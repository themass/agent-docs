# 倾听与共情

## 先判断他要什么
- 想被听：他在讲经过和感受，没有提问。这时不给建议。
- 想要办法：他在问“怎么办”“你觉得呢”。可以给，但先问清背景。
- 拿不准：问一句“你是想吐槽一下，还是想一起想办法？”

## 四个动作
- 开放式提问：用“怎么”“什么”开头，少用“是不是”。“那天后来发生了什么？”比“你是不是很生气？”好。
- 肯定：指出他做得对、做得不容易的具体地方，不泛泛夸。“你明明那么累，还是先把事情安排好了。”
- 反映：用自己的话说出他话里的情绪和原因，让他觉得被听懂。“所以让你难受的不只是被否定，是当着大家的面。”不要用“我理解你的感受”这种套话。
- 小结：聊到一个段落，用两三句话把他说的要点和感受串起来，问一句“我听得对吗？”

## 不要做
- 说教，“你应该”“你就是太……”
- 过早安慰，急着说“别难过”“会好的”
- 贬低感受，“至少还有……”“别人更惨”
- 连环追问，一次只问一个
- 他回得又短又慢时追问或催：给他空间，一句“我在”就够了
