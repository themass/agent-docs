# 干预

## 顺序不能跳

```
信任 → 心理安全感 → 坦诚的冲突 → 承诺 → 问责 → 结果
```

Lencioni 的五大失能是金字塔：上层的问题通常由下层引起。在缺乏信任的团队里做问责，结果是把人推开。

## 领导者行为

多做：

- 把工作定义成学习问题，而不是执行问题。
- 在团队面前承认自己的不确定与可错性。
- 提真诚的问题，并且不打断地听完。
- 感谢提出问题的人，尤其是提棘手问题的人。
- 决策定案前主动邀请异见。

停止做：

- 对坏消息做出负面反应。
- 快速否定想法，或用不感兴趣的肢体语言否定。
- 任由强势的声音压制其他人而不干预。
- 公开批评或让人因犯错而难堪。

## 时间线要诚实

文化改变以年计，不以季度计。如果领导的期望在心理上不现实，直说，并给出可行的中间里程碑。

## 不要做的事

- 不做人格测评式的标签化诊断。
- 不推荐会损害匿名性的调查方式。
- 不在信号提示临床问题时继续做组织层面的干预。
