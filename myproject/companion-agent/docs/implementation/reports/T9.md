# T9 报告：记忆（memory_hub）

日期：2026-11-09。依据：D §10、P §6.5。

## 做了什么

1. **memory_hub 独立包**（`src/memory_hub/`，与 companion 解耦，pyproject 已加入打包）：
   - `scope.py`：复合用户 id `app:uid`；用户 id 含冒号或应用名不合法直接拒绝。
   - `config.py`：`AppConfig` 与启动校验。两个应用共用 collection、或共用令牌环境变量，都拒绝启动（D §10.7）。
   - `hub.py`：`MemoryHub.from_config(configs, build_port)` 为每个应用构造自己的端口；`for_app(app)` 返回 `ScopedMemory`。`ScopedMemory` 的方法签名与 `MemoryPort` 一致，外部传入的是应用内用户 id，内部统一加前缀。`kinds` 过滤在端口之外做。
2. **记忆接口 v1** `api/http/routers/memory_v1.py`（`/api/agent/v1/memory`）：
   - 事实：`GET /facts`（分页、`has_more`）、`POST /facts`、`PATCH /facts/{id}`、`DELETE /facts/{id}`。
   - 事件：`GET /events`、`POST /events`、`PATCH /events/{id}`（状态）、`DELETE /events/{id}`。
   - `GET /profile`：返回 `null`。L3 画像由 P4 汇总任务生成，现在不编造。
