# T8 报告：工具、授权、确认

日期：2026-11-09。依据：T §1–§3。

## 做了什么

1. **工具定义** `domain/tools/spec.py`：`ToolSpec`、`Permission`（READ/AUTO/CONFIRM）、`SideEffect`、`ToolContext`。构造期六条规则，违反即拒绝注册：不可逆不能 AUTO；EXTERNAL 必须 CONFIRM；AUTO 必须有副作用；名称不能命中禁用模式；参数模型不能含身份字段；CONFIRM 必须有确认标题。
2. **授权判定** `domain/tools/policy.py`：顺序固定为「白名单 → 参数 → 权限」；参数指纹（sha256 前 16 位）；结果按预算截断；本回合白名单 = 产品 ∩ 声明。
3. **注册表** `domain/tools/registry.py`：名称唯一，按产品过滤。
4. **运行时** `app/tools/runtime.py`：校验参数（错误只回显字段名与错误类型，不回显输入）→ 授权 → CONFIRM 只建记录不执行 / 其余执行（超时、异常、截断）→ 审计。身份只来自 `ToolTurn`（服务端上下文），参数里的 `user_id` 会被忽略。
5. **确认闭环** `app/tools/confirmation.py`：允许时先 `pending→processing` 认领（原子），用快照参数执行，再 `processing→executed/failed`；同一条确认只生效一次；拒绝不执行；过期标记；结果写一条 `kind='action'` 消息，不起新的模型回合。
6. **首批工具** `app/tools/builtin.py`：`get_current_time`、`recall_facts`、`recall_events`、`remember_fact`、`remember_event`（AUTO）、`create_reminder`（CONFIRM，仅 roleplay）。
7. **LangChain 声明** `adapters/brain/tools.py`：模型看到的名称、描述、参数 Schema；直接调用协程会报错，执行只能经中间件。
8. **中间件** `adapters/brain/graph_middleware.py`：`ToolAuthorizationMiddleware` 改为调用 `ToolRuntime`，没有回合上下文时拒绝（fail closed）。`ToolAuditMiddleware` 退化为占位（审计在运行时内完成，避免同一次调用写两条）。
9. **MCP 策略修正** `domain/tools/mcp_policy.py`：白名单默认拒绝（旧实现空白名单表示全部，与设计相反）；每工具权限；未声明一律 confirm；禁用模式双重过滤；`CircuitBreaker`（连续 5 次失败开路，冷却 60 秒）。
10. **端口与存储**：`ports/tools.py`（`ToolCallStore`）；`ConfirmationStore.finish`；MySQL 的 `MysqlToolCallStore` 与 `finish`。
