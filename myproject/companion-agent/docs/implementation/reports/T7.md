# T7 报告：角色目录与语言

日期：2026-11-09。依据：P §4、§5；D §5、§3.2。决定：**283 个目录角色全部上线**；阿拉伯语先用英文占位并标记机翻。

## 做了什么

1. **目录文件**：`roles/catalog/catalog.json`（283 个角色）、`catalog-zh.json`（中文覆盖）、`NOTICE`（MIT，来自 agency-agents）。从 Java `vvv-roles` 原样复制，Python 不依赖 Java 仓库。
2. **领域（纯逻辑）** `domain/roles/catalog.py`：
   - 解析与校验，任一失败即拒绝加载：id 格式、系统 id 不得以 `u_` 开头、id 重复、与内置人设 id 冲突、分类引用不存在、提示词为空、覆盖文件引用了不存在的 id。
   - `RoleIndex`：搜索（分类、关键字、精选）、按语言取展示字段，缺失回退英文。
   - `negotiate_locale`：显式 `locale` 优先，其次 `Accept-Language`（按 q 值排序），默认 `zh-CN`。
3. **加载器** `adapters/roles/catalog_files.py`：读取 JSON 文件并调用解析。
4. **服务** `app/roles/service.py`：系统角色与自建角色合并列表；系统角色只读（修改/删除 403）；自建角色仅本人可见可改（他人与不存在统一 404）；自建角色 id 为 `u_` + ULID。
5. **接口** `api/http/routers/roles.py`（前缀 `/api/agent/v1`）：`GET /divisions`、`GET /roles`（`division`、`q`、`featured`、`mine`、`locale`、`limit`、`offset`）、`GET/POST /roles`、`GET/PUT/DELETE /roles/{id}`。响应带 `locale` 与 `dir`。
6. **装配**：`create_app(roles=RoleService(...))` 传入时挂载。
