# T3 报告：身份验证

## 完成
- `ports/auth.py`：`IdentityError`（401）、`AuthUnavailable`（503）、`parse_bearer`、`CredentialVerifier`。
- `adapters/auth/redis_token.py`：`RedisTokenVerifier`。
  - 键格式校验：`token_` 前缀 + 标准 Base64 字母表 + 长度上限（Java 的 token 含 `+ / =`，D §4 修订后的规则）。
  - 只保留 `id`；`pwd`、`pwdHash` 随解析结束一并丢弃，不进入返回值。
  - Redis 不可用 → `AuthUnavailable` → 503（不是 401，避免用户被误导去重新登录）。
- `api/http/deps.py`：401/503 映射。
- `bootstrap/checks.py`：fail-closed 启动检查。生产环境拒绝 `allow_all` 与假大脑。`create_app` 在容器建好后调用它。
- `config.py`：`COMPANION_AUTH_VERIFIER`、`AUTH_REDIS_URL`。

## 验证
- 启动检查的三种情形都按预期拒绝或放行（已用 `python -c` 确认）。
- 导入与契约：通过。
