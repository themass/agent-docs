# T6 报告：SSE 接口与事件

日期：2026-11-09。依据：D §7.1–7.3、A §5.4、P §3.5。

## 做了什么

1. **SSE 编码**（`api/sse/encoder.py`）：`id:` / `event:` / `data:`，data 用 `json.dumps`，换行已转义，一帧不会被拆开；`: keepalive` 注释帧。
2. **事件流**（`api/sse/stream.py`）：
   - 首连：有运行中回合则先发 `turn.snapshot`，再实时订阅。
   - `Last-Event-ID` 续传：早于保留窗口发 `gone`。
   - 无事件时每 15 秒发心跳。
   - draining 时发 `reconnect {after_ms}` 并结束流。
3. **会话接口**（`api/http/routers/chat.py`，前缀 `/api/agent/v1`）：
   - `POST /sessions/{id}/messages`（202，返回 disposition；draining 时 503；安全拒绝 422）
   - `GET /sessions/{id}/events`（SSE）
   - `POST /sessions/{id}/cancel`
   - `GET /sessions/{id}/queue`、`DELETE /sessions/{id}/queue/{message_id}`（已排空/合并返回 409）
   - `GET /sessions/{id}/messages`（`before` 游标，`limit` 1–100）
4. **停机**（`api/http/drain.py` + `serve.py`）：`DrainingServer` 覆盖 `handle_exit`，第一次信号置 draining，等回合收尾至多 45 秒，再交给 uvicorn 原逻辑；第二次信号立即退出。
5. **运行器与提交的事件对齐 D §7.2**：`turn.started`、`message.created`（每条用户输入）、`input.merged/steered/queued`、`message.delta {delta}`、`message.done {assistant_message_id}`、`step`、`turn.restarted`。
6. **端口**：`TurnControlPort` 增加 `wait_events`、`active_turn`、`tail_event_id`、`oldest_event_id`。
7. **装配**：`create_app(chat=ChatApi(...))` 传入时挂载会话路由；`app.state.companion.drain` 提供停机状态。

## 设计偏离 / 未完成

1. **D §7.1 的其余接口未实现**：会话列表/新建/改名/删除、`regenerate`、`retry`、`continue`、`queue/clear`、`queue/retry`、`PATCH/DELETE /messages/{id}`、`/uploads`、`/actions/*`（已有旧路由，需按 T8 重做）、`/roles`（T7）、`/memory/*`（T9，旧路由待替换）、`DELETE /me`（O §3）、`/healthz`、`/readyz`（目前只有 `/health`）。
2. **用户 id 映射**：`owner_id` 在数据库里是整数，路由用 `int(user_id)`，非数字返回 404。需要与 Java 登录态的 id 类型确认（T3 的 `RedisTokenVerifier` 已经只解析 `id`，类型待核对）。
3. **turn.snapshot 字段**：目前只带 `text`，`user_message_ids` 与 `steps` 为空，T6 之后补齐。
4. **step 事件**：D §7.2 定义 `kind` 为 `read/reason/check/answer`，目前工具事件暂用 `kind: "tool"`。解题步骤由 T11 的 skill 产出时再对齐。
5. **停机与回合计数未接线**：`DrainState.turn_started/turn_finished` 尚未被 `TurnRunner` 调用，`wait_idle` 目前等不到任何回合。T13 接线后再测 45 秒收尾。
6. **撤回不软删消息**：`withdraw` 只改队列状态，D §7.1 要求同时软删对应用户消息，T6 之后补上。
7. **chat 路由未在 `create_app` 默认挂载**：需要 Redis 与 MySQL 仓储的组合（`bootstrap/container.py` 尚未提供），T13 组装。
