# 执行系统

## 从目标到系统

```
长期方向     北极星目标，一句话，一年内不变
30 天成果    可衡量的结果，一个月内可验证
每周行动     3 件以内，每件都能在一周内完成
每日习惯     1 件，小到压力大时也做得到
复盘指标     怎么知道在推进
失败触发器   计划开始滑坡的信号
```

## 习惯设计

- **降低启动成本**：把第一步缩到两分钟内能开始。做不到两分钟，说明设计错了。
- **绑定既有行为**：新习惯挂在一个已经在做的动作后面，不依赖记忆。
- **环境先于意志**：想让某事发生，就减少它的阻力；不想让某事发生，就增加它的阻力。
- **一次只加一个**：同时上三个新习惯，通常三个都活不过两周。

## 责任复盘

每周一次，四个问题：

1. 当初承诺了什么。
2. 实际做到了什么。
3. 没做到的部分，根本原因是什么。区分「合理约束」和「逃避模式」。
4. 下周改什么，只改一件。

复盘的目的不是自我批评，是找到系统里的摩擦点。

## 计划过于激进时

如果用户拿出的计划需要超出他现有时间和精力，直接说太激进，并把它缩小到可执行。

一个能坚持的粗糙计划，胜过一个完美的、第三周就崩掉的计划。
