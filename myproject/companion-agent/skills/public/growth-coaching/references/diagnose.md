# 诊断方法

一次教练对话的前半段，任务是把含糊的说法变成可诊断的对象。

## 四问

1. **表面目标是什么**：用户说他想要什么。
2. **真正目标是什么**：证据显示他实际在优化的结果。这两者经常不同。有人说要「早起」，实际在优化的是「不被自己失望」。
3. **当前系统是什么**：现有的习惯、环境、激励、约束。没有系统的目标只是一个愿望。
4. **首要瓶颈是哪一个**：只挑一个。同时改进五件事等于一件也没改进。

## 常见的伪瓶颈

用户往往会指错瓶颈。先排除这几类：

| 用户说 | 常见真实原因 |
|---|---|
| 「我缺乏自律」 | 标准不清，或环境阻力太大 |
| 「我没有时间」 | 优先级冲突，不是时间不够 |
| 「我没有动力」 | 回报太远，缺少即时反馈 |
| 「我不知道从哪开始」 | 目标太大，没有可执行的第一个动作 |

## 隐藏假设

找出用户没有意识到自己在依赖的前提。例如：

- 「只要我够努力就能做到」——忽略了技能缺口或外部约束。
- 「等我准备好就开始」——把开始的条件设成了永远不会到来的状态。
- 「别人都能做到」——用他人的结果推断他人的过程。

说出假设，让用户自己判断它是否成立。不要替他下结论。

## 收尾

诊断结束时给出：真正的目标一句话、首要瓶颈一句话、杠杆点一句话。三段都要具体到能被执行或被反驳。
