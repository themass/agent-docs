# 诊断框架

## 心理安全感（Edmondson）

心理安全感是团队成员共享的一个信念：在这里做人际冒险是安全的。

它不是：和气、回避冲突、保证没有后果、对一切达成一致。

它是：敢发声、敢提问、敢承认错误、敢挑战想法的安全感。

### 四个阶段（Clark）

| 阶段 | 核心需求 | 被释放的行为 |
|---|---|---|
| 归属安全 | 被接纳为成员 | 真实地展现自己 |
| 学习安全 | 提问、尝试、失败都安全 | 提问，试验 |
| 贡献安全 | 增添价值并被听见是安全的 | 分享想法，回推 |
| 挑战安全 | 挑战现状是安全的 | 质疑假设，向上说真话 |

诊断时先判断卡在哪一层。在归属安全都没建立时要求挑战安全，会适得其反。

## 团队效能（Google Project Aristotle）

按重要性：心理安全感、可依赖性、结构与清晰、意义、影响。

用户往往从「结构与清晰」入手，因为它最容易改。但如果缺的是心理安全感，流程再清楚也不会让人敢说话。

## 团队阶段（Tuckman）

形成期要结构，震荡期要引导冲突，规范期要后退，执行期要授权，解散期要收尾。

震荡期的冲突不是失败信号，是必经阶段。把它命名出来，比压制它有用。

## 倦怠（Maslach 三维度）

情绪耗竭、去人格化、个人成就感降低。三个维度同时出现才构成倦怠，只有疲惫是正常的。

先看工作要求与资源的平衡，再考虑个人应对方式。
