# NaviForge 快捷键（0.1.3）

权威定义：`apps/extension/src/lib/toolkit-shortcuts.ts`。

在 **普通 http(s) 网页** 上使用，Chrome 窗口在前台。Mac 上截图相关请用 **Option + Shift**（不要只按 Option）。

| 按键 (Mac) | Windows | 命令 | 功能 | 安装默认 |
|------------|---------|------|------|----------|
| ⌥⇧N | Alt+Shift+N | `nf-open-toolkit` | 网页内工具浮层 | ✅ |
| ⌥⇧A | Alt+Shift+A | `nf-capture-visible` | 可见区域截图 | ✅ |
| ⌥⇧S | Alt+Shift+S | `nf-capture-full` | 全页截图 | ✅ |
| ⌘⇧S | Ctrl+Shift+S | `nf-screenshot-studio` | 截图工作室（框选 · 标注 · OCR） | ✅ |
| ⌥⇧T | Alt+Shift+T | `nf-translate` | 就地翻译 | 需在 chrome://extensions/shortcuts 绑定 |

Chrome 每个扩展最多 **4 个** 默认快捷键；翻译不占默认位。
