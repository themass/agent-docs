NaviForge Privacy Policy

Last updated: 2026-11-06

NaviForge (“we”, “the Product”, “the extension”) is a Chrome browser extension that helps you run an AI agent on web pages you choose. This privacy policy explains what personal or sensitive user data we collect, how we handle and use it, how we store it, and how we share it. Each of these topics is addressed in its own section below.

Developer / data controller contact: justbegin010@gmail.com

1. Summary

  • Local-first by default: Chat history, settings, optional API keys, and workspace files are stored on your device.
  • Bring your own model (BYOK, default): Task content goes to the LLM or search provider you configure. We do not receive that traffic in BYOK mode.
  • Optional hosted inference: If you enable managed mode and sign in, requests may go through our API gateway for metering.
  • Optional ads: When enabled in a release, Google AdSense may load in iframes from pages we host.
  • We do not sell your personal or sensitive user data.

2. Personal and sensitive user data we collect

Depending on which features you use, the Product may process:

Category Examples When
Web page content Visible text, DOM summaries, links, titles, URLs of tabs you use with the Agent When you run Agent or toolkit actions on a page
Screenshots & images Page captures, OCR crops, screenshot-studio exports When you capture, OCR, or attach images

We do not require a NaviForge account for the default BYOK experience. We do not intentionally collect government IDs, payment card numbers, or precise GPS location through the extension UI. Chrome permissions (site access, storage, optional debugger) are used only to provide listed features.

3. How we handle and use data

We use the data above solely to:

  • Perform your requested tasks (Agent runs, OCR, screenshot studio, toolkit actions).
  • Authenticate to services you configure (your LLM/search keys, or hosted login tokens).
  • Persist local history and settings across sessions.
  • Improve reliability on your device (optional local site profiles / playbooks).
  • Meter optional hosted usage if you use managed inference.
  • Show optional advertising if AdSense is enabled in that release.
  • Respond to support requests you send to our contact email.

We do not use your page content to train our own models unless a future hosted feature explicitly discloses that and you opt in (today: no).

4. How we store data

Location What Your control
Your browser (chrome.storage) Settings, optional API keys, extension activity logs Clear via Settings → Advanced / retention controls
Your computer (~/NaviForge when used) Saved files, scripts, shots, optional audio Delete the folder yourself; extension “clear” may not remove it
Your chosen LLM / search provider Prompt content you send during a run Subject to that provider’s privacy policy
NaviForge hosted API (optional) Account session and usage metering Email us to request account deletion
Ad embed host (optional) AdSense scripts on pages we host for iframes See Google’s policies; ads off until configured

Security: Keys and tokens are stored in extension storage when you opt in; avoid storing keys on shared devices. Third-party API calls use HTTPS when the provider supports it. Optional Local Host binds to 127.0.0.1 with a Bearer token and is not part of the Chrome Web Store package.

Retention: Adjust activity retention in Settings → Privacy. Disabling “Store API Key” and saving removes stored keys. Hosted account records are kept while the account is active and as needed for billing or abuse prevention.

We share or transmit data only as described below. We do not sell personal or sensitive user data.

Optional Local Host (separate install) exchanges data only between processes on your machine and the extension; it does not send browsing data to NaviForge servers.

6. Advertising

When enabled, NaviForge may show Google AdSense display ads inside extension pages (side panel, settings, screenshot studio). Ads load in an iframe from pages we host—not inside the extension package. Google may use cookies or similar technologies; see Google’s advertising policies. Ads remain off until we configure AdSense embed URLs in a release.

7. Your choices and rights

  • Use BYOK without creating a NaviForge account.
  • Leave Network Plane, Modify Header, DOM inject/probe, and ads off (defaults / release configuration).
  • Clear local extension data in Settings; delete ~/NaviForge manually if needed.
  • Revoke Chrome site permissions or uninstall the extension at any time.
  • For hosted accounts or privacy questions, email justbegin010@gmail.com to request access, correction, or deletion of account-related data we hold.

8. Children

NaviForge is not directed at children under 13. We do not knowingly collect personal information from children under 13. If you believe a child has provided such data, contact us and we will delete it.

9. International transfers

If you use third-party APIs or hosted mode, data may be processed in countries where those providers or our gateway operate. Those transfers are necessary to provide the feature you requested and are subject to the recipient’s terms and applicable law.

10. Changes

We may update this policy. The “Last updated” date above will change when we do. Material changes will also be noted in extension release notes when practical. Continued use after an update means you accept the revised policy.
