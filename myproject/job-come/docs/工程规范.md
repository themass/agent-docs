## JobCome 特有硬约束

1. **DeerFlow**：仅 `adapters/deerflow_session_client.py` 可 `import deerflow`；不用 IM channels。
2. **业务真相**：Profile、面试库在 MySQL；DeerFlow 只做对话态。
3. **访客**：`jc_guest` / `jc_session` Cookie；`GuestMigrationService.claim`。
4. **MCP**：`user_id` 来自 Run metadata，不信模型参数。
