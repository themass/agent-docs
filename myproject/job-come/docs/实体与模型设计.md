## 4. Profile JSON（`schemas/profile_payload.py`）

与 MVP §5.1 一一对应：

- `ProfileContact`, `ProfileLink`
- `ProfileExperience`, `ProfileEducation`, `ProfileSkill`, `ProfileProject`, `StarStory`
- `ProfileConstraints`, `ProfilePreferences`, `ProfileMeta`
- `ProfilePayload`（根）

`jc_profile.payload` 存 **JSON**；ORM `Profile.payload` 类型为 `ProfilePayload`。

---

## 5. 关键关系

```text
User 1──1 UserMeta
User 1──* Profile (user_id)
GuestSession 1──* Profile (guest_session_id)
Profile 1──* ProfileSource
Profile 1──* ResumeDraft
Profile 1──* Job
Profile 1──0..1 Campaign
Profile 1──* InterviewRecord
InterviewRecord 1──* InterviewQuestion
InterviewQuestion 1──* AnswerAttempt
Profile 1──* MockSession
User 1──* AgentSession
```

**属主约束：** `Profile` 上 `user_id` 与 `guest_session_id` **恰有一个非空**（应用层 + CHECK 可选）。
