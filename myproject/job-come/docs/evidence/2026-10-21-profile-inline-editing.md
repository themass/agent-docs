# 核对页面：简历原位编辑

验收日期：2026-10-21（Asia/Shanghai）。

## 用户要求与本轮范围

用户不接受「上方阅读简历、下方展开另一套编辑表单」的流程。本轮将核对页改成直接点击简历内容编辑，不改优化稿生成或导出接口，不改保存契约。

## 实现

- ResumeStudio 移除「快速编辑」「展开表单编辑」以及底部独立表单和大块确认说明。
- ProfileOverview 在明确收到页面草稿控制器时展示 ProfileDocumentEditor；compact/只读调用维持原路径，不给其他页面偷偷开启编辑。
- InlineProfileField 默认展示原文和轻量编辑标识；鼠标或键盘激活后原位出现输入框/多行文本。每次输入即写入共享页面草稿，而非等待 blur 才写入。失焦回到文本展示；Escape 取消本字段本次修改，单行 Enter 或多行 Ctrl/Cmd+Enter 结束编辑；中文输入法确认不误触结束。
- 姓名、联系方式、个人简介、经历职位/公司/起止日期/地点/范围/要点、项目、教育及技能均可原位编辑。新增/删除操作位于对应段落；删除需确认，实际写库仍由顶部保存触发。
- 学历与专业分别保留；经历/项目按稳定 ID 定位，技能修改保留 level/evidence，未操作字段和未知扩展数据继续通过 spread 保留。
- 继续使用既有 useProfileDraft：顶部保存、确认前先保存、在途编辑保护、版本冲突提示和未保存离开提醒。照片仍走已有独立端点。未保存时禁用语言转换，避免异步翻译覆盖当前输入。
- 技能证据和经历关联技能不会为了展示而扁平化覆盖；经历关联技能可在对应经历内展开修改。
