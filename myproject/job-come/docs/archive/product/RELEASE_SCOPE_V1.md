# JC V1 发布范围

更新时间：2026-10-12

## 产品定位

JC 服务正在主动跳槽、寻求职业提升的**泛知识工作者**。第一批用户以互联网公司的知识工作岗位为主，覆盖研发、产品、设计、运营、市场、销售、客户成功、项目/交付、数据、HR、财务、法务等岗位；不把产品限定为研发。

## V1 用户闭环

1. 上传简历，解析并确认个人档案。
2. 在确认后的档案上进行可追踪的事实修订、审稿和 HTML/PDF/DOCX 导出。
3. 粘贴职位描述，解析职位并生成匹配/差距分析；差距分析不阻断简历优化或导出。
4. 进入模拟面试：warmup 可不绑定 JD，target 面试必须绑定 JD；一次一题，保存回答、反馈和最佳答案。
5. 记录真实面试：公司、岗位、日期、轮次、问题和复盘；真实问题进入个人题库，可重复练习。
6. 通过账号、档案、职位和 session 归属校验保护数据边界。

## 明确不属于 V1

LiveKit 实时语音模拟、手机端、Zoom/腾讯会议等真实会议实时监听和实时作答属于 V2，不应在 V1 验收中宣称可用。

## 发布判断

当前代码已达到“可上线候选版本、进入真实环境联调和用户测试”的阶段；真实 MySQL/Redis、LLM、DeerFlow 完整 agent、TOS、邮件和生产部署仍需按验收门禁逐项确认。
