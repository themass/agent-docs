# JC 架构与目录规范（V1）

> 状态：V1 上线前的执行规范。最后更新：2026-10-15。

## 1. 进程与部署边界

V1 采用 **两个业务进程、一个公开域名**：

```text
浏览器
  └─ http://jc.sspacee.com
       └─ Nginx
           ├─ /          → Next.js Web（:3000）
           ├─ /api/v1/*  → JC API（:8000）
           └─ /health    → JC API（:8000）

JC API（一个 Python 进程）
  ├─ FastAPI HTTP / SSE
  ├─ 业务服务、MySQL、Redis、TOS
  └─ 内嵌 DeerFlow Harness、JC MCP、Skills、Prompts
```

- **Agent 不是第三个常驻服务。** V1 在 API 进程内调用锁定版本的 DeerFlow Harness；因此 API 暂时必须以 `--workers 1` 运行。
- **前端与 API 同域。** 公共 API 固定为 `/api/v1`；Nginx 代理避免浏览器 CORS 与 Cookie 跨域问题。
- **不开放通用浏览器与通用网络。** 受控的 JD 读取仅通过 JC 的安全服务；模型不能自行确认档案 patch。

## 2. 已落地目录与职责

```text
frontend/web/                   Next.js 前端
backend/server/                 FastAPI 服务端工程
├─ src/jc/api/                  HTTP 路由与鉴权入口
├─ src/jc/services/             业务编排、导出、文档处理、存储访问
├─ src/jc/db|models|stores/     数据模型、会话和持久化
├─ src/jc/agent/                Agent 会话、流式输出和任务编排代码
├─ src/jc/adapters|mcp/         DeerFlow 适配层与受控 JC MCP
├─ alembic/ tests/ fixtures/    数据库迁移、回归测试和测试素材
└─ nginx/                       服务端反向代理样例
backend/agent/                  Agent 资产与运行配置
├─ skills/                      DeerFlow Skill 的唯一源
├─ prompts/                     LLM / Agent Prompt 的唯一源
├─ deerflow/                    Harness、MCP、产品规则配置
├─ llm/ litellm/                模型路由与 LiteLLM 配置
└─ ../infra/                    其他后端运行基础设施
docs/                           产品、架构、验收与部署文档
scripts/                        开发、校验、安装和运维脚本
```

Agent 与服务端仍是一个 Python API 进程；将 Agent 的**资产与配置**从服务端代码中物理分离，不等于引入额外常驻 Agent 进程。

## 3. 路径约束

- Python / Alembic / `uv.lock` 的工作目录固定为 `backend/server/`。
- 服务端 `.env` 位于 `backend/server/.env`；模板是 `backend/server/.env.example`。
- Web 工作目录固定为 `frontend/web/`。
- Agent 资源由服务端配置以 `../agent/...` 相对 `backend/server/` 读取。
- 所有根脚本从项目根运行，例如 `./scripts/dev.sh`；脚本会定位上述目录。

## 4. 运行时命名契约

| 资源 | 契约 |
|---|---|
| 主站 | `http://jc.sspacee.com` |
| API | `/api/v1` |
| Python 包 / MCP | `jc` / `jc_*` |
| Redis | `jc:{env}:{namespace}:{identifier}` |
| TOS 对象 | `jc/{env}/...` |
| DeerFlow runtime | `.data/deerflow/runtime/`，由 `JC_DEERFLOW_RUNTIME_HOME` 配置 |
| Canonical Skills | `backend/agent/skills/`，由 `DEER_FLOW_SKILLS_PATH` 配置 |

项目根 `.deer-flow/` 为早期本地生成缓存，不属于 V1 运行时输入或发布物。
