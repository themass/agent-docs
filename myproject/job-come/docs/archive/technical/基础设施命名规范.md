# JC 基础设施命名规范

> 适用范围：JC V1 的应用名、生产主站、Redis、MySQL 与对象存储。产品短名称统一为 **JC**。

## 1. 统一标识

| 对象 | 规范值 |
|---|---|
| 产品/服务短名称 | `jc` |
| 灰度主站 | `http://jc.sspacee.com` |
| 同源 API 基址 | `/api/v1` |
| 健康检查 | `http://jc.sspacee.com/health` |
| OpenAPI 文档 | `http://jc.sspacee.com/api/v1/docs` |
| 前端 API 环境变量 | `NEXT_PUBLIC_API_BASE=/api/v1` |

前端和 FastAPI 必须通过同一域名对外提供服务：Nginx 把 `/` 代理给 Next.js，把 `/api/v1/` 代理给 FastAPI。不单独配置前端跨域访问 API，也不引入浏览器 CORS 白名单作为正常链路。

当前域名按 HTTP 用于灰度验收。**在对真实用户正式开放前，必须迁移到 HTTPS，并将 `JC_COOKIE_SECURE=true`。**

## 2. Redis

### 2.1 Key 格式

所有 JC 拥有的 Redis key 必须使用：

```text
jc:{environment}:{namespace}:{identifier}
```

环境取值固定为：

```text
dev | test | staging | prod
```

当前 `.env` 开发配置：

```env
JC_REDIS_KEY_PREFIX=jc:dev:
```

生产环境必须显式设置：

```env
JC_REDIS_KEY_PREFIX=jc:prod:
```

示例：

```text
jc:dev:session:sess_01...
jc:prod:guest:gst_01...
jc:prod:email-verify:{token_hash}
jc:prod:profile-patch:cfm_01...
jc:prod:rate-limit:upload:{ip_hash}
jc:prod:queue:...
```

### 2.2 命名空间

| 命名空间 | 责任 |
|---|---|
| `session` | 已登录会话 |
| `guest` | 访客会话热缓存 |
| `email-verify` | 邮箱验证令牌 |
| `profile-patch` | Agent 提交、等待用户确认的档案 patch |
| `rate-limit` | 限流计数器 |
| `cache` | 可重建缓存 |
| `lock` | 分布式锁 |
| `queue` | 异步队列消息与状态 |

### 2.3 实现约束

- 业务模块不得自行拼接 `jc:`、环境前缀或 Redis key。
- 必须通过 `src/jc/redis_client.py` 的 `redis_key_prefix()` / `redis_key()` 生成 key。
- 新 namespace 先登记在本文档，再接入代码与监控。
- token、邮箱、手机号、原始文件名和档案文本不能直接放入 key；需要标识时使用系统 ID 或不可逆 hash。
- 不同环境不得共用前缀；测试不得连接生产 Redis DB 或使用 `jc:prod:`。

旧格式 `jc:email_verify:*`、`jc:patch_confirm:*`、`jc:rl:*` 禁止新增。已有缓存不做兼容读取，按 TTL 自然淘汰。

## 3. MySQL

短期在共享数据库 `vpn` 内使用表名前缀隔离：

```text
jc_user
jc_profile
jc_guest_session
jc_...
```

约束：

- 所有 JC 表使用 `jc_` 前缀；迁移和 SQL 不得读写无此前缀的业务表。
- 生产账号仅授予 `jc_%` 所需的最小权限。
- 长期目标是独立 schema（建议 `jc`）和独立最小权限账号；迁移前先完成备份、回滚和只读校验方案。

## 4. TOS / CDN

TOS 当前使用共享 bucket；object key 必须隔离为：

```text
jc/{environment}/profiles/{profile_id}/source/{source_id}.{extension}
jc/{environment}/profiles/{profile_id}/export/{export_id}.{extension}
```

约束：

- 不使用用户上传的原始文件名作为 object key。
- key 不包含邮箱、手机号、身份证号、简历正文等敏感信息。
- CDN 下载域名可保持独立的 `files.job.sspacee.com`；它是文件分发域名，不是主站域名。
- 存储路径改造需同时处理旧对象读取、迁移与回滚；V1 上线前应优先让新写入符合该规范。
