## 1. 命名约定

### 1.1 表前缀（冻结）

| 前缀 | 含义 | 示例 |
|------|------|------|
| **`jc_`** | JobCome 业务表（本库 `vpn` 内） | `jc_user`, `jc_profile` |
| **`df_`** | DeerFlow checkpointer（若与业务同库，由 harness 自建） | 不手写，随 DeerFlow pin 版本 |

**规则：**

- 全部小写 + 下划线：`jc_interview_question`
- 主键：`id`（`CHAR(26)` ULID 或 `VARCHAR(32)`，与 API 的 `usr_xxx` / `prof_xxx` 一致）
- 时间：`created_at` / `updated_at`（`DATETIME(3)` UTC）
- 软删：`deleted_at` NULL 表示未删
- 外键：逻辑外键（M1 应用层校验为主；可选 DB FK 在 W1 后加）

### 1.2 Redis Key 前缀（冻结）

| Key 模式 | 用途 | TTL |
|----------|------|-----|
| `jc:session:{sess_id}` | 已登录 Session → `user_id` | 7d 滑动 |
| `jc:guest:{gst_id}` | 访客 Session 热缓存（镜像 `jc_guest_session`） | 30d |
| `jc:rl:upload:{ip}` | 上传限流 | 1h |
| `jc:rl:elevate:{gst_id}` | 访客拔高每日配额 | 至当日 24:00 |
| `jc:arq:*` | ARQ 任务队列 | — |

**Session 真相：** M1 以 **Redis 为主**；`jc_guest_session` 表做持久化与认领审计。

## 3. 表清单（按域）

### 3.1 账户与鉴权

| 表名 | 实体 | 说明 |
|------|------|------|
| `jc_user` | UserAccount | 邮箱、密码哈希、验证状态、`status` |
| `jc_user_meta` | UserProfileMeta | 昵称、头像、语言、默认拔高档位、通知偏好 |
| `jc_guest_session` | GuestSession | 访客 ID、过期、认领用户、最后活跃 |
| `jc_password_reset` | — | 重置密码一次性 token（哈希存库） |

`jc_user` 核心字段：

| 列 | 类型 | 说明 |
|----|------|------|
| `id` | VARCHAR(32) PK | `usr_` 前缀业务 ID |
| `email` | VARCHAR(255) UNIQUE | 登录邮箱 |
| `password_hash` | VARCHAR(255) | bcrypt/argon2 |
| `email_verified_at` | DATETIME(3) NULL | |
| `status` | ENUM | `active` / `deleted` |
| `password_changed_at` | DATETIME(3) | |
| `created_at` / `updated_at` / `deleted_at` | DATETIME(3) | |

### 3.2 求职档案（Profile）

| 表名 | 实体 | 说明 |
|------|------|------|
| `jc_profile` | Profile | 简历真相源；属主 `user_id` 或 `guest_session_id` 二选一 |
| `jc_profile_source` | — | 上传原件元数据（S3 key、文件名、解析状态） |

`jc_profile` 核心字段：

| 列 | 类型 | 说明 |
|----|------|------|
| `id` | VARCHAR(32) PK | `prof_` |
| `user_id` | VARCHAR(32) NULL | 已登录属主 |
| `guest_session_id` | VARCHAR(32) NULL | 访客属主 |
| `status` | ENUM | `draft` / `confirmed` |
| `version` | INT | 乐观锁 |
| `locale` | VARCHAR(16) | `zh-CN` |
| `payload` | JSON | contact / experiences / education / skills / starStories 等（对齐 MVP §5.1） |
| `confirmed_at` | DATETIME(3) NULL | |

**索引：** `(user_id)`, `(guest_session_id)`, `UNIQUE(user_id) WHERE active`（MVP 单活跃档案，应用层保证）

大字段策略：嵌套结构放 **`payload` JSON**；列表筛选用冗余列（如 `payload->>'$.contact.name'` 或后续生成列）。

### 3.3 简历拔高 / 导出

| 表名 | 实体 | 说明 |
|------|------|------|
| `jc_resume_draft` | ResumeDraft / ResumeVariant | 拔高结果、`elevation_map` JSON |
| `jc_export_job` | — | 异步导出任务状态、S3 下载 key |

`jc_resume_draft`：`profile_id`, `job_id` NULL, `elevation_level`, `template_id`, `sections` JSON, `elevation_map` JSON, `reviewer_status`, `exported_at`。

### 3.4 岗位与进攻计划（P1，W3+）

| 表名 | 实体 | 说明 |
|------|------|------|
| `jc_job` | Job | JD 原文、requirements、fit 分 |
| `jc_campaign` | Campaign | 练手/目标期、进度 JSON |

### 3.5 面试飞轮（W5–W8 核心）

| 表名 | 实体 | 说明 |
|------|------|------|
| `jc_interview_record` | InterviewRecord | 真面一场 |
| `jc_interview_question` | InterviewQuestion | 题库单题（个人库） |
| `jc_answer_attempt` | AnswerAttempt | 某题一次作答 + 参考答法 |
| `jc_mock_session` | MockSession | 一轮模拟 |

关系：

```text
jc_interview_record 1 ── * jc_interview_question
jc_interview_question 1 ── * jc_answer_attempt
jc_mock_session * ── * jc_interview_question  （question_ids JSON 或关联表 jc_mock_session_question）
```

M1 简化：`jc_mock_session.question_ids` 用 **JSON 数组** 存 ID 列表。

### 3.6 投递与追踪（P1，W9+）

| 表名 | 实体 | 说明 |
|------|------|------|
| `jc_application` | Application | 用户标记已投递 |
| `jc_offer_track` | OfferTrack | 目标岗位阶段 |

### 3.7 Agent 会话映射

| 表名 | 实体 | 说明 |
|------|------|------|
| `jc_agent_session` | — | JobCome session ↔ DeerFlow `thread_id`；`user_id`, `profile_id`, `kind`（resume/coach） |

DeerFlow 对话 checkpoint **不在 `jc_` 表**；由 DeerFlow harness 写入 `df_*` 或独立库（部署时配置）。

## 4. M1 分期建表

| 阶段 | 表 | 周次 |

| W0 | `jc_user`, `jc_user_meta`, `jc_guest_session`, `jc_password_reset` | 账户 |

### 5.2 MySQL（业务库）

| 项 | 值 |
|----|-----|
| Host | `mysql.sspacee.com` |
| Port | `6666` |
| Database | **`vpn`** |
| User | 见 `.env`（**勿提交 git**） |

连接串格式：

```text
mysql+aiomysql://{user}:{password}@mysql.sspacee.com:6666/vpn?charset=utf8mb4
```
