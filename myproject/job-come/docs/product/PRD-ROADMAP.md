# PRD-ROADMAP：产品路线图

- **状态**：V1 后续计划；V2 需求方向待立项后拆分
- **最后更新**：2026-10-15

## 当前阶段

JC 处于 **V1 上线候选版本 → 真实环境联调 → 首批用户验收** 的阶段。当前优先级不是继续扩张功能，而是关闭发布门禁，验证完整闭环在真实 MySQL、Redis、TOS、LLM、邮件、域名与 Agent 环境下稳定可用。

## 近期：V1 发布前

1. 部署真实服务并配置域名、反向代理、环境变量与密钥。
2. 完成 API、Agent、MCP、LLM、对象存储、邮件的端到端联调。
3. 进行真实浏览器、权限隔离、并发取消、重启恢复、导出质量和文档解析评测。
4. 以首批互联网知识工作者完成建档、简历、JD、模拟面试、复盘的完整任务作为用户验收。

## 下一个版本：三项核心能力

| 优先级 | 能力 | 用户价值 | 进入开发前的前置条件 |
|---|---|---|---|
| P0 | LiveKit 实时语音模拟面试 | 用接近真实面试的语音交互训练表达、节奏与追问 | 实时会话架构、录音与数据留存规则、延迟与成本基线 |

| P0 | Zoom / 腾讯会议实时面试辅助 | 在用户真实面试时理解问题并给出辅助建议 | 明示授权、隐私/平台合规评估、本地音频处理、实时延迟与安全策略 |

## 后续增强方向

- **个人题库飞轮**：真实问题的脱敏归档、标签、检索、针对性训练；社区共享必须自愿、脱敏且后置。
- **职业材料质量体系**：中英简历、目标岗位版本管理、审稿量表、可解释差距建议。
- **机会管理**：目标公司、申请状态、准备任务和复盘节奏；保持用户主动控制，不进入自动投递。
- **Agent 编排演进**：只有在 V1 的隔离、持久化、成本和可观测性出现明确瓶颈时，评估更强的工作流编排。

## 不做清单（持续有效）

- 一键投递、自动填写站点、自动发送申请；
- 在未获得用户明确确认时修改个人事实；
- 默认开启的通用浏览器、通用网络访问或裸数据库工具。
