## 1. 第一版一句话

> **访客/用户能上传简历 → 拔高导出 → 登录后 Agent 改稿与模拟 → 真面记题 → 库抽题再模拟 → 保存参考答法**

**验收一句话：** 作者 + 5 个熟人浏览器跑通：上传 → 拔高导出 → 模拟一轮 → 真面后记 3 题 → 第二次模拟抽到库内题 → 对比参考答法。

**灵魂在 W5–W8 面试飞轮**；W1–W4 是必要前置。

## 2. 第一版做什么 / 不做什么

### 2.1 必须做（P0）

| # | 用户能力 | 产品模块 |
|---|----------|----------|
| 1 | **账户**：注册、登录、忘记密码、注销；个人信息维护 | 设置 |
| 2 | **访客**：上传、手改、**拔高预览/改档位**；登录后草稿不丢 | 简历 Agent 页 |
| 3 | **建档**：PDF/DOCX 解析 → 核对 Profile → 确认 | 档案中心 |
| 4 | **拔高 + 导出**：三档拔高 → PDF + Word（**登录后**） | 档案中心 |
| 5 | **简历 Agent**：多轮对话改稿（**登录后**） | 简历 Agent 页 |
| 6 | **记真题**：真面后录入公司/岗位/轮次/≥3 题 | 面试中心 |
| 7 | **个人面试库** + 模拟**优先抽库内题** | 面试中心 |
| 8 | **参考答法** + 同一题多轮对比 | 面试中心 |
| 9 | **文字模拟面试**（练手模式） | 面试辅导 Agent 页 |

### 2.2 应该做（P1，冲突时可砍细度）

| # | 用户能力 |
|---|----------|
| 10 | 粘贴 JD → Fit 报告 → 练手/目标标签 |
| 11 | 进攻计划（练手期/目标期、达标进度规则版） |
| 12 | 目标模式模拟（语气/压力与练手区分） |
| 13 | 岗位与面试、导出记录关联 |
| 14 | OfferTrack / 达标追踪雏形 |

### 2.3 第一版不做

| 不做 | 原因 |
|------|------|
| 代投递、爬虫聚合招聘 | 红线 |
| 社区题库、支付 | M4+ / 未定 |
| LiveKit 语音模拟 | M3 |
| 通用八股题库 | 差异化是个人真面库 |
| 多 Profile | MVP 单活跃档案 |
| DeerFlow IM（飞书/Telegram） | C 端 Web 自有入口 |

## 3. 访客与登录（第一版冻结）

| 能力 | 访客 | 已登录 |
|------|------|--------|
| 上传、解析、手改 Profile | ✅ | ✅ |
| 拔高预览 / 改档位 | ✅ | ✅ |
| 导出 PDF/Word | ❌ | ✅ |
| 简历 Agent 多轮对话 | ❌ | ✅ |
| 面试模拟 / 记题 / 题库 | ❌ | ✅ |
| 设置 / 注销 / 数据导出 | ❌ | ✅ |

**合并规则：** 登录时 `GuestMigrationService.claim()` — 无账户 Profile 则直接认领；有冲突则二选一（覆盖草稿 / 保留账户）。

## 4. 用户可见页面（第一版）

| 路由 | 页面 | 访客 | 登录 |
|------|------|------|------|
| `/auth/*` | 注册、登录、忘记密码 | ✅ | ✅ |
| `/resume-agent` | 简历优化（编辑器 + Agent） | 编辑+拔高预览 | 全功能 |
| `/profile/*` | 档案核对、导出 | 核对 | 导出 |
| `/jobs/*` | JD、Fit、标签 | ❌ | ✅ |
| `/campaign` | 进攻计划 | ❌ | ✅ |
| `/interview-coach` | 模拟 / 记题 / 题库 / 参考答法 | ❌ | ✅ |
| `/settings/*` | 账户、个人信息、隐私 | ❌ | ✅ |

**两大 Agent 产品页：**

1. **简历优化** — 左编辑器 + 中拔高预览 + 右 Agent 对话（访客右侧登录蒙层）
2. **面试辅导** — 模式：文字模拟 / 记真题 / 题库 / 练参考答法

## 5. 技术方案（第一版）

> **前端架构、独立部署、API 交互、登录态 Cookie：** 见 **[前端架构与鉴权.md](前端架构与鉴权.md)**（开工前端/API 联调必读）。

### 5.1 架构总览

```text
┌──────────────────────────────────────────────────────────┐
│  apps/web (Next.js)                                       │
│  AuthProvider · ProfileEditor · CoachModePicker           │
└────────────────────────────┬─────────────────────────────┘
                             │ HTTPS / SSE
┌────────────────────────────▼─────────────────────────────┐
│  jobcome/api (FastAPI)                                    │
│  Auth · Guest · Profile · Resume · Interview · Coach API  │
│  Actor 鉴权 · GuestMigration · ResumeRenderEngine           │
└────────────┬───────────────────────────┬─────────────────┘
             │                           │
             ▼                           ▼
┌────────────────────────┐   ┌─────────────────────────────┐
│  MySQL (vpn) + Redis   │   │  DeerFlow harness（黑盒）    │
│  业务真相 + checkpoint  │   │  DeerFlowSessionClient       │
│  S3 简历/导出           │   │  skills/ + extensions_config │
└────────────────────────┘   └──────────────┬──────────────┘
                                              │ stdio MCP
                               ┌──────────────▼──────────────┐
                               │  jobcome.mcp.server          │
                               │  profile_* · bank_* · ...    │
                               └─────────────────────────────┘
```

### 5.2 技术栈

| 层 | 选型 |
|----|------|
| 前端 | Next.js 15 + TypeScript + Tailwind + shadcn/ui |
| API | Python **3.11+** + FastAPI |
| **Agent** | **DeerFlow harness**（pin 版本；不接 IM） |
| ORM | SQLAlchemy 2.0 |
| 队列 | ARQ + Redis |
| 存储 | **MySQL 8**（库 `vpn`）+ Redis + S3/MinIO |
| 导出 | `ResumeRenderEngine`（自研，不经 Agent） |

### 5.3 DeerFlow：Skill + MCP（第一版清单）

**Skill**（`job-come/skills/public/`）：

| Skill | 用途 | 触发 |
|-------|------|------|
| `resume-ingest` | 解析规范、待确认字段 | 上传后 Ingest |
| `resume-writer` | 拔高三档 | 拔高预览、导出前 |
| `resume-reviewer` | 硬事实/拔高句检查 | Writer 后（子 Agent） |
| `coach-mock` | 文字模拟 | 面试辅导页 |
| `coach-archive` | 记真题 | 录入表单辅助 |
| `coach-answer` | 参考答法 | 练题页 |

**MCP**（`extensions_config.json` → `jobcome` server）：

| Tool | 作用 |
|------|------|
| `jobcome_profile_get` | 读 Profile |
| `jobcome_profile_patch` | Agent 改字段 |
| `jobcome_bank_search_questions` | 抽库 |
| `jobcome_interview_save` | 记真题 |
| `jobcome_answer_save_attempt` | 保存参考答法 |

配置模板：[deploy/deerflow/extensions_config.example.json](../deploy/deerflow/extensions_config.example.json)

**多租户：** Run `metadata` 写入 `user_id` / `profile_id`；MCP **不信**模型传入的 tenant。

### 5.4 包结构（第一版脚手架）

```text
job-come/
├── apps/web/
├── src/jobcome/
│   ├── common/           # 跨域工具沉淀（trace、ids、crypto…）
│   ├── api/              # auth, profile, resume, coach, interview
│   ├── services/         # 业务编排
│   ├── stores/           # PostgreSQL
│   ├── adapters/
│   │   ├── deerflow_session_client.py   # 唯一 import deerflow
│   │   └── resume_render_engine.py
│   └── agent/mcp/        # MCP Server 实现
├── skills/public/        # DeerFlow Skill
├── deploy/deerflow/
└── docs/
```

### 5.5 Agent 与产品页映射

| 场景 | DeerFlow | JobCome |
|------|----------|---------|
| 访客拔高预览 | `run_once` + `resume-writer` Skill | `ResumeService.elevate` |
| 登录改稿对话 | `thread` SSE + `resume-writer` | `ResumeService` + SSE 代理 |
| 文字模拟 | `thread` + `coach-mock` | `InterviewCoachService` |
| 记题 | 表单为主；可选 `coach-archive` | `InterviewService.archive` |
| 抽库模拟 | `coach-mock` + MCP `bank_search` | `MockQuestionPlanner` |

### 6.3 冲突时砍 scope（保 P0）

**绝不砍：** 建档导出、记题、库抽题、参考答法、账户/访客。

**可砍到 M2：** Fit 精细度、英文模板 polish、ATS 深度、求职信。

## 7. 验收标准（W12）

| ID | 验收项 | 标准 |
|----|--------|------|
| A | 建档导出 | 上传 → 核对 → 拔高 → PDF/Word，**< 15 分钟** |
| B | 访客路径 | 未登录可手改+拔高预览；导出/Agent 引导登录；登录不丢稿 |
| C | 记题 | 一场面 **≥ 3 题** 入库 |
| D | 库驱动 | 第二次模拟 **≥ 1 题来自库** |
| E | 参考答法 | 同一题 **≥ 2 次** Attempt，可标 best |
| F | 全链路 | 固定脚本一次跑通 |
| G | 账户 | 注册/登录/重置/注销可用 |
