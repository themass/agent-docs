# JobCome V1 用户测试指南

更新时间：2026-10-12

## 测试前

按 [RUNBOOK.md](./RUNBOOK.md) 配置本地环境和账号，不要把密钥写进仓库。启动 API 与 Web 后，用一个测试账号开始；再用第二个账号验证数据隔离。

## 主流程

1. 登录，上传一份真实但已脱敏的简历。
2. 检查解析档案；确认后编辑事实，预览并导出 HTML/PDF/DOCX。
3. 粘贴一个互联网职位描述，检查岗位解析和匹配差距；确认低匹配不会阻断导出。
4. 进入 warmup 模拟面试，再创建绑定 JD 的 target 面试；回答多题、保存答案、查看五维反馈并重复练习。
5. 在“真实面试归档”录入公司、岗位、日期、问题和复盘；回到题库搜索并再次练习。

请至少使用研发、产品/运营、HR 或财务中的各一份非研发岗位样本，确认流程不是只对工程岗位有效。

## 边界和异常

验证过期/重复确认 token、错误 profile/session/job、空回答、结束后的写入、恶意职位描述中的指令文本、跨账号访问都会被拒绝或不改变数据。确认失败后检查原档案未被修改。

## V2 边界

V1 不提供 LiveKit 实时语音、手机端，也不监听 Zoom/腾讯会议或在真实会议中实时给答案；这些功能请记录为后续需求，不作为本轮缺陷。

## 补充功能（2026-10-13）

定向岗位页可显式勾选“动态读取公开页面”。不登录、不绕过验证码；失败请粘贴 JD。成功后核对来源/时间。导出失败不再返回伪 PDF，检查失败提示并修改简历重试。

验收边界与证据请参见 `V1_SUPPLEMENTAL_STATUS.md`；当前可以测试，但不代表生产上线批准。
