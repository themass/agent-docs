## 1. 产品全貌（一张图）

### 1.1 我们做什么

**JobCome** = 帮知识工作者 **拿下目标公司 Offer** 的独立 Web 产品。

不是「改完简历就结束」，而是：

```
备稿（拔高 + 导出）→ 练手攒真面经验 → 面试库越厚 → 模拟越准 → 攻目标公司 → Offer
```

**定位句：**

> 帮用户发现招聘、拔高简历，先用非目标公司练手，再攻目标公司；每次真面与模拟都沉淀真题，形成个人面试库，越练越强。导出 PDF/Word，**投递用户自己做**。

### 1.2 三条差异化（产品灵魂）

| # | 差异化 | 一句话 |
|---|--------|--------|
| 1 | **剑指 Offer** | 成功 = 目标公司签约，不是导出 PDF |
| 2 | **先练手、后攻目标** | 非目标公司攒经验，达标后再打 dream company |
| 3 | **面试库飞轮** | 记真题 → 抽库模拟 → 迭代最佳答法 → 再真面 → 库更厚 |

缺任何一条，都会塌成「又一个 AI 改简历」。

### 1.3 核心飞轮

```
        ┌──────────────┐
        │  档案 + 导出  │  ← 简历优化 Agent 页
        └──────┬───────┘
               ▼
        ┌──────────────┐     用户自行投递（产品不代投）
        │ 练手 + 模拟  │  ← 面试辅导 Agent 页
        └──────┬───────┘
               ▼
        ┌──────────────┐
        │ 真面后记真题  │──► 个人面试库
        └──────┬───────┘
               ▼
        ┌──────────────┐
        │ 库抽题再模拟  │──► 参考答法迭代
        └──────┬───────┘
               ▼
        ┌──────────────┐
        │ 攻目标 → Offer│
        └──────────────┘
```

### 1.4 两大 Agent 产品页（用户可见面貌）

| 页面 | 用户做什么 | Agent 做什么 | 人工做什么 |
|------|------------|--------------|------------|
| **简历优化 Agent** | 上传旧简历；与 Agent 对话改稿；**手改表单** | 拔高建议、针对性改写、圆场提示 | 确认档案；**导出 PDF/Word**；自行投递 |
| **面试辅导 Agent** | 选题库互动 / 模拟面 / 记真题 / 练参考答法 | 出题、点评、生成参考答法（绑定档案） | 真面后录入；达标后攻目标岗 |

**交互形态演进：**

| 阶段 | 简历页 | 面试辅导页 |
|------|--------|------------|
| M1 MVP | 文字对话（DeerFlow） | 文字模拟 + 记题 |
| M2 | 同左 + 更强 JD 针对性 | 目标高压模式、答案版本对比 |
| M3 | — | **LiveKit 实时语音**模拟面；手机端进 Room |
| M4 | — | 语音复盘、异步录音转写 |

┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│ 档案中心  │ │ 岗位中心  │ │ 进攻计划  │ │ 面试中心  │ │   设置   │
│建档·拔高  │ │JD·Fit   │ │练手→目标 │ │模拟·记题  │ │账户·隐私 │
│导出      │ │标签     │ │达标     │ │题库·答法  │ │个人信息 │
└──────────┘ └──────────┘ └──────────┘ └──────────┘ └──────────┘
     M1           M1          M1           M1★         M1
                              M2加强        M2/M3语音
     M2 Scout聚合招聘 ─────────────────────────────────────────►

## 2. 长期计划（里程碑）

按 **产品成熟度** 分阶段，时间可按团队节奏伸缩；阶段之间 **能力叠加**，不推翻重做。

### 2.1 阶段总览

| 阶段 | 时间（建议） | 主题 | 北极星 |
|------|--------------|------|--------|
| **M0 规格** | 1–2 周 | 对齐文档、样本、技术 spike | 三人读完路线图能复述产品 |
| **M1 MVP** | 12 周 | 文字闭环 + 面试库飞轮 | 熟人可完整演示竖切 |
| **M2 攻目标** | +1 季度 | 招聘发现、高压模拟、追踪加厚 | 作者自用完成一轮真实求职 |
| **M3 语音与多端** | +1 季度 | LiveKit、手机、语音模拟面 | 语音模拟面可端到端 |
| **M4 网络效应** | +1 季度 | 社区题库、同岗聚类 | 练手沉淀可帮他人 |
| **M5+ 商业化** | 未定 | 付费、B 端、数据校准 | 可持续 + Offer 案例 |

### 2.2 M1 — MVP（第一期，当前焦点）

**目标：** 浏览器里跑通 **文字** 竖切，证明面试库飞轮有价值。

**必须交付：**

- 简历优化页：上传 → 编辑器 + Hermes 对话 → PDF/Word 导出
- 面试辅导页：模拟（文字）→ 记 ≥3 题 → 库抽题再模拟 → 参考答法对比
- 练手/目标标签、Campaign 达标（规则版）
- 粘贴 JD + Fit（P1）

**验收一句话：**

> 上传简历 → 拔高导出 → 模拟一轮 → 真面后记 3 道题 → 第二次模拟抽到库内题 → 保存并对比参考答法。

**不做：** LiveKit、爬虫聚合、社区题库、支付、语音。

### 2.3 M2 — 攻目标加厚

**目标：** 从「能演示」到「作者真能用来攻 dream company」。

| 能力 | 说明 |
|------|------|
| Scout 招聘聚合 | 公开源 / RSS / 目录；仍不代投 |
| 目标模式高压模拟 | 语气、追问深度、复盘维度升级 |
| 答案版本对比 | 「比上周进步」可视化 |
| OfferTrack | 练手 vs 目标结果追踪 |
| Campaign 强化 | 达标建议更可解释 |
| agentmemory（可选） | Hermes 跨会话记忆；**题库仍以 PG 为准** |

### 2.4 M3 — 语音与多端

**目标：** 模拟面从「打字」升级到「真面感」；手机可参与。

| 能力 | 说明 |
|------|------|
| **LiveKit 语音模拟面** | 面试辅导页新增语音模式；STT→Hermes→TTS |
| LiveKit Web 组件 | `VoiceCoachRoom` |
| 手机 SDK | 同一 Room；或异步录音上传 |
| 语音复盘 | 房间结束 → 转写 → `interview_save` |
| 简历页语音口述（可选） | 经历口述 → `profile_patch` |

**技术：** `VoiceInteractionChannel`；不改 Hermes / LiveKit 源码。

### 2.5 M4 — 网络效应

**目标：** 练手公司攒的题，帮后来人攻同类目标岗。

| 能力 | 说明 |
|------|------|
| 社区题库 | 自愿脱敏贡献 |
| 同岗位聚类 | 题型、挂点标签 |
| 高赞参考答法 | 须结合自身 Profile 改写 |
| 漏斗数据校准 | 练手几场、库多少题后 Offer 率最高 |

### 2.6 M5+ — 商业化（单独开一轮）

候选：求职季套餐、按模拟轮次、Offer 赏金、B 端高校/顾问。**M1–M4 不接支付。**

## 3. 中期计划（按季度）

假设 M1 从 **T0** 开工，12 周结束为 **T0+12w**：

| 季度 | 日历（示例） | 产品重点 | 技术重点 |
|------|--------------|----------|----------|
| **Q0** | T0 → T0+12w | M1 MVP 演示冻结 | Hermes MCP + 两大 Agent 页 + 飞轮 |
| **Q1** | +13w → +26w | M2 攻目标、Scout | 招聘源适配器、高压 Coach Skill |
| **Q2** | +27w → +39w | M3 LiveKit 语音模拟 | `livekit/` 胶水层、Mobile |
| **Q3** | +40w → +52w | M4 社区题库试点 | 脱敏、治理、聚类 |
| **Q4** | +53w | 商业化调研 + M5 选型 | 计费、隐私合规加固 |

每季度 **只设一个必须打穿的主题**；新功能先问落在漏斗哪段：备稿、练手、攻目标、Offer。

## 4. 短期计划（M1 十二周拆解）

### 4.1 分期目标

| 子阶段 | 周 | 产品目标 | 技术目标 |
|--------|-----|----------|----------|
| **S1 能投** | W1–W2 | 有亮简历可导出 | Profile + Hermes Ingest + 导出引擎 |
| **S2 能选岗** | W3–W4 | 知道练手/目标 | JD、Fit、Campaign 标签 |
| **S3 飞轮★** | W5–W8 | 面试库闭环 | 模拟、记题、抽库、参考答法 |
| **S4 能攻** | W9–W11 | 目标模式、追踪 | Application、OfferTrack 雏形 |
| **S5 冻结** | W12 | 全链路演示 | E2E、演示数据、文档冻结 |

### 4.2 逐周计划

| 周 | 产品交付 | 技术交付 | 演示检查点 |
|----|----------|----------|------------|
| **W0** | 路线图、回归样本收齐 | **Actor 鉴权** + GuestSession + claim + Auth | 访客可上传手改 |
| **W1** | 简历页访客/登录双态 + Header | ProfileService + Ingest；登录后 Agent | 登录不丢稿 E2E |
| **W2** | 拔高 + PDF/Word 导出 | `ResumeRenderEngine`、resume-coach Skill | 15 分钟内可导出 |
| **W3** | 粘贴 JD、Fit 报告 | `JobService`、analyst Skill | 两 JD 建议相反 |
| **W4** | 练手/目标标签、进攻建议 | `CampaignService` | 2 练手 + 1 目标可见 |
| **W5** | 面试辅导页 v0：文字模拟 | `InterviewCoachService`、coach-mock | 完成 1 轮模拟 |
| **W6** | 记真题表单 | `InterviewService.archive` | 一场面 ≥3 题入库 |
| **W7** | 个人题库列表 | `MockQuestionPlanner` 抽库 | 第二次模拟抽到库内题 |
| **W8** | 参考答法 + 版本对比 | `AnswerAttempt`、coach-answer | 同一题 2 次对比 |
| **W9** | 岗位与面试关联 | Application 快照 | 题可链到 JD |
| **W10** | 目标模式模拟 | coach 高压 prompt | 练手/目标语气可区分 |
| **W11** | 达标进度、结果追踪 | OfferTrack 雏形 | 仪表盘可见进度 |
| **W12** | **演示冻结** | E2E、脱敏演示账号 | 全链路脚本一次跑通 |

### 4.3 M1 优先级（冲突时砍 scope）

**绝不砍（P0）：** 建档导出、记题、库抽题、参考答法。

**可砍到 M2（P1）：** Fit 精细度、求职信、ATS 深度检测、英文模板 polish。

**本阶段不做：** LiveKit、爬虫、社区、支付。

### 4.4 M1 双周节拍（进入开发后）

每个双周固定四件事：

1. **一条竖切故事**（本周必须能跑的用户路径）
2. **一组回归样本**（3 简历 × 2 JD）
3. **一次硬事实抽检**（5 段：公司/时间/项目是否还在档案里）
4. **一次真人试用**（非团队成员）

## 5. 成功指标（分阶段）

| 阶段 | 指标 | 目标 |
|------|------|------|
| M1 | 演示全链路成功率 | 100%（固定脚本） |
| M1 | 建档→导出耗时 | < 15 分钟 |
| M1 | 个人库题目数（演示账号） | ≥ 10 题 |
| M1 | 库驱动抽题命中率 | 第二次模拟 ≥1 题来自库 |
| M2 | 作者真实求职漏斗 | 有记录的可复盘 |
| M3 | 语音模拟完成率 | 熟人试用 ≥3 人完成一轮 |
| M4 | 社区贡献率 | 自愿脱敏 >0 |
| 长期 | 目标公司 Offer | 个案验证（产品终极北极星） |

### 已冻结决策（摘要）

| 项 | 结论 |
|----|------|
| 形态 | 独立 Web |
| 投递 | 不代投 |
| 简历 | 可拔高，硬事实不造假 |
| 策略 | 先练手后攻目标 |
| Agent 底座 | **DeerFlow harness** + JobCome Skill/MCP |

| **账户** | 访客可手改 + **拔高预览**；导出 / Agent 对话需登录 |
| 付费 | MVP 不做 |

## 附录：从长期到短期的拆解逻辑

```text
愿景（Offer + 面试库飞轮）
    ↓
M1–M4 里程碑（能力叠加）
    ↓
季度主题（每季只打一个洞）
    ↓
M1 十二周（S1–S5 子阶段）
    ↓
双周竖切（可演示故事）
```

**原则：** 长期计划定 **方向与不做什么**；短期计划定 **本周能演示什么**。若本周演示与 M1 验收无关，砍掉。
