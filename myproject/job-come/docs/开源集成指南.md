## 2. 集成原则

1. **真相源**：Profile / Job / Interview 只写 `jobcome` MCP 或 FastAPI Service
2. **社区 Skill**：fork 到 `skills/custom/`，改 tool 调用，不直引 GitHub 子模块
3. **外部 MCP**：只读/解析/搜索；**禁止**代投、裸 DB、未授权爬虫默认可用
4. **路由**：`extensions_config.example.json` 用 `routing.keywords` 分流

### 不建议集成

- 代投 / 自动填表 Skill
- 无 MCP 绑定的「纯聊天写简历」Skill（易编造）
- InterviewLM 等 **招聘方** 工具

## 4. 推荐开源 MCP

| 优先级 | 项目 | 用途 | 配置 |
|--------|------|------|------|
| ⭐⭐⭐ | [microsoft/markitdown](https://github.com/microsoft/markitdown) (`markitdown-mcp`) | PDF/DOCX→MD | `uv run markitdown-mcp` |
| ⭐⭐⭐ | [@modelcontextprotocol/server-fetch](https://github.com/modelcontextprotocol/servers/tree/main/src/fetch) | 招聘页 URL→文本 | npx，无 key |
| ⭐⭐⭐ | [tavily-ai/tavily-mcp](https://github.com/tavily-ai/tavily-mcp) | 公司调研 | `TAVILY_API_KEY` |
| ⭐⭐ | [brave/brave-search-mcp-server](https://github.com/brave/brave-search-mcp-server) | 搜索备选 | `BRAVE_API_KEY` |
| ⭐⭐ | [can4hou6joeng4/boss-agent-cli](https://github.com/can4hou6joeng4/boss-agent-cli) | BOSS/智联 **只读** | `enabled: false` 默认 |
| ⭐ | [jppoamaral/resume-ats-mcp](https://github.com/jppoamaral/resume-ats-mcp) | ATS 关键词 | 可内化到 `ResumeReviewer` |
| ⭐ | [nspady/google-calendar-mcp](https://github.com/nspady/google-calendar-mcp) | 面试日程 | M2+ |

### 不建议默认开启

- LinkedIn 爬虫 MCP（封号风险、国内价值低）
- mergedao/mcp-jobs 等 ToS 不清的爬虫
- 裸 PostgreSQL MCP

启用方式：复制 `deploy/deerflow/extensions_config.example.json` 中对应块，`enabled: true` + 配 env。
