# 深空场 DeepSpace Field — 产品规格与开发规划

> 版本：1.0 | 2026-09-11  
> 状态：范围冻结草案（随目录摄取迭代数量，不改原则）  
> 关联：`DEEPSPACE_FIELD_DESIGN.md`（引擎与太阳系 MVP）、本文件（产品覆盖与路线）

---

## 1. 产品定义

浏览器里的 **可漫游宇宙结构百科 + 科学官讲解**。

用户沿八层宏观尺度飞行；**已知被探索的天体与现象以目录形式尽量收全**；每层有正确几何；少数目标做成可进入近景；地球可落地看山河并可剖视内部；数字人讲解当前选中对象并接受追问。

**承诺**：能搜到、能飞到它所在的那一层、能看懂它是哪一类、能听到基于观测档案的说明。  
**不承诺**：每一个目录条目都有独立体积世界、科研级动力学仿真、视界内部旅游。

**不是**：太空射击、全宇宙 N-body、监控地球的 OSINT 产品。

---

## 2. 「覆盖所有已知被探索的」怎么验收

用户想到的创生之柱、KBC 空洞、巨引源等只是例子。覆盖标准是下面三条同时成立，而不是精品近景堆完所有 NGC。

### 2.1 三条覆盖

| 级别 | 含义 | 完成态 |
|------|------|--------|
| **A. 类型覆盖** | 天文学已确认的宏观天体类型与现象类型，产品里都有定义、至少 1 个可到达范例、科学官能讲 | 类型表全绿 |
| **B. 目录覆盖** | 进入公开专业目录、有坐标/证认的对象，可搜索、可定位到正确层，以标记+档案卡呈现 | 按目录版本号验收（见 §4） |
| **C. 场景覆盖** | 每层有定位场景；每类型有少量英雄近景 | 英雄清单有上限，可运营追加 |

A + B = 「所有已知被探索的」产品含义。  
C = 喜欢度与演示，刻意做少。

### 2.2 「已知被探索」的操作定义

计入目录当且仅当满足：

1. 被 SIMBAD / NED / MPC / Gaia / NASA Horizons / NASA Exoplanet Archive / MAST / IAU 等 **公开专业目录或观测档案** 收录；  
2. 有可用于飞行的位置（天球坐标，或太阳系星历，或宇宙学方向+特征距离）；  
3. 能写清发现/证认状态（确认 / 候选 / 有争议）。

不计入或降级为「候选」：未证认传闻、把民间星座故事当物理天体、视界内部、未发表坐标。

**目录条目默认不是 3D 世界。** 默认是：正确层级上的一点（或纤维/盘面）+ 档案卡 + 讲解。只有英雄清单升级为体积/地形/剖视。

### 2.3 明确不做（永久）

- 微观粒子物理作为可飞场景
- 把空洞、长城、巨引源做成可着陆行星
- 把可视化（暗物质雾、false-color 星云）说成直接光学成像
- 为每一个小行星、每一颗 Gaia 星做独立网格
- 把 God's Eye View 的航班/摄像头搬进宇宙场

## 3. 八层运行时（尺度不混渲）

| 层 | 内容 | 运行时 |
|----|------|--------|
| U0 可观测宇宙 | CMB 天球、哈勃流示意、深场方向 | R3F 天球 |
| U1 宇宙网 | 纤维、空洞、长城、超星系团、巨引源方向 | R3F 点云示意 |
| U2 星系际 | 星系、星系团、本星系群 | R3F 标记 + 少数盘面 |
| U3 银河 | 盘、臂、银心、球状星团、银河 POI | R3F 银河模型 |
| U4 恒星环境 | 星云、星团、多星系统 | 标记；英雄体积云 |
| U5 致密与高能 | 黑洞、脉冲星、SN 遗迹、暴、喷流 | 标记；少数特效近景 |
| U6 行星系统 | 太阳系；系外系统目录点 | 现有太阳系场景 |
| U7 行星本体 | 地表山河、内部圈层 | MapStage 或 Cesium；自研剖面 |

跃迁动画掩盖 LOD/引擎切换。HUD 永远显示当前层。

地球外表默认 MapStage（卫星+DEM+水）。城市真 3D 再开 Cesium（可借鉴 God's Eye View 的地球能力，不集成其 GEOINT 层）。

## 4. 目录覆盖（B 级）— 已知探索的底账

产品以 **摄取流水线 + 标准化条目** 收编目录，而不是手写天体名单。前端加载分层索引（亮星/Messier 先，Gaia 远场按 LOD）。

### 4.1 天体目录（v1 必须接入或给出版本缺口）

| 域 | 权威源 | v1 目标 | 呈现 |
|----|--------|---------|------|
| 太阳系大天体 | Horizons / SPICE、IAU 行星卫星名录 | 行星、矮行星、主要卫星 | U6 真轨道 |
| 太阳系小天体 | MPC、JPL SBDB | 编号小行星/彗星可搜；亮/近/著名子集显示轨道 | U6 点/轨 |
| 近地与探测 | Horizons 航天器 | 主要探测器航迹可选开 | U6 轨 |
| 恒星（近邻） | Hipparcos / HYG / Gaia 近邻切片 | 肉眼星 + 近邻恒星可飞到 | 点 + 光谱色 |
| 恒星（巡天） | Gaia DR3 抽样 LOD | 银盘密度正确，不一次加载十亿 | 多分辨率点云 |
| 双星/多星 | WDS / 轨道解子集 | 有轨道解的可搜；英雄做 α Cen 等 | 目录；少数真轨道 |
| 深空经典 | Messier 110、Caldwell、NGC/IC | **全表可搜可定位** | U2–U5 标记 |
| 星云/HII 等 | Sharpless、著名 PNe/SNR 表 | 全表可搜；英雄体积另列 | 标记 |
| 星团 | 疏散/球状星团表 | 全表可搜 | 标记 |
| 星系 | RC3 / NED 常用子集、本星系群 | 亮星系可搜；本星系群相对位置正确 | 标记/盘面 |
| 星系团 | Abell / 著名团 | 可搜，落在 U2 | 团标记 |
| 宇宙学结构 | 空洞/长城/超星系团编译表 | 公知结构全收（含争议标注） | U1 示意 |
| 系外行星 | NASA Exoplanet Archive（确认行星） | 可搜宿主星；不画假地表 | U4/U6 点 |
| 星座 | IAU 88 边界 + 连线 | 全开全关 | 天球叠加 |
| 著名观测场 | Hubble/JWST 深场、EHT 目标 | 可飞到方向并看烘焙图 | 广告牌/近景 |

Gaia 全量是 LOD 问题，不是「不做」。验收：**任意落入已摄取快照、可被 SIMBAD 解析的名称，搜索能命中并飞到。** 快照版本、条数、日期写在关于页。

### 4.2 现象类型（A 级必须全绿）

现象不是都能做成一个球，但每类必须有：定义、范例天体、科学官能讲、目录可筛。用户没点名的类型也不能缺类型卡。

- **引力与几何**：轨道、潮汐、Roche、引力透镜、引力波事件（天球定位+时间）、进动
- **辐射与波段**：可见、IR、射电、X、伽马、false-color 合成（必须讲解）
- **恒星演化**：主序、红巨星、行星状星云、SN II/Ia、超新星遗迹、脉冲星/磁星、白矮星、恒星级黑洞
- **星系活动**：旋涡、并合、潮汐尾、AGN、类星体、Blazar、射电喷流
- **星际介质**：发射/反射/暗星云、分子云、恒星形成、原行星盘
- **致密与极端**：SMBH、吸积盘、喷流、潮汐瓦解（事件类）
- **行星系统**：岩石/气态/冰巨、环、卫星、矮行星、小天体、陨击、极光、地球水循环（仅英雄）
- **宇宙学**：膨胀/红移、CMB、宇宙网、空洞、纤维、长城、超星系团、巨引源/拉尼亚凯亚、暗物质（示意+诚实说明）、暗能量（解释卡，无实体）
- **时域**：变星、新星、超新星、GRB、FRB、太阳耀发——事件目录+天球闪标
- **太阳物理**：光球/色球/日冕、CME（太阳英雄后期）
- **人类探索**：着陆点、轨道器、望远镜指向场——「已被探索」的第二索引

### 4.3 英雄近景（C 级，首发上限）

- U7：地球山河；地球圈层剖视；（可选）月、火
- U6：太阳系完整巡航
- U5：Sgr A*
- U4：创生之柱；（v1.1）船底座或猎户座大星云；α Cen 双星
- U3：银河定位模型
- U1：KBC、巨引源/拉尼亚凯亚、一座长城结构（写清是哪一条）
- U0：CMB 天球

其余已知对象全部走目录标记，不阻塞首发。

## 5. 科学官数字人

- 角色：科学官。领航是系统能力（「带我去」触发飞行）。
- 位置：U0–U6 座舱半身像；U7 地表以后再考虑世界空间。
- 开场：选中条目 → 30～90 秒预制旁白。
- 追问：检索该条目档案 + 类型卡 + 同层目录。
- v1：半身 GLB + TTS + 文字问答。语音为 v2。
- 可静音、可跳过、不挡天空。

---

## 6. 主循环与 UX

打开默认地球或内太阳系，再提供「拉到宇宙网」。  
左：八层目录 + 搜索（中英别名、Messier/NGC/IAU）。  
中：3D。右下：科学官。顶栏：层、名称、真实距离、显示尺度、来源、确认/候选。  
分享 URL：层 + 目标 + 相机 + 讲解时间码。

---

## 7. 喜欢度

垂直用户会喜欢的条件：搜得到已知对象、层不迷路、落地地球、能问「这是不是假的」。  
不靠天体数量取胜，靠地球↔宇宙网的尺度对比和诚实讲解。  
指标：完航率、讲解完播率、搜索后飞达率、问答有用率、分享链接数。

## 8. 开发规划（2 人全职粗估）

| 阶段 | 周 | 交付 | 验收 |
|------|----|------|------|
| 0 产品壳 | 2 | 八层 HUD、搜索、跃迁、科学官空壳 | 能说出当前层 |
| 1 太阳系 | 3–4 | 加固现有 MVP | 大天体可飞可达 |
| 2 地球 U7 | 4–5 | MapStage 落地；圈层剖视 | 木星→流域→剖视 |
| 3 目录骨架 | 4 | Messier + IAU 星座 + 本星系群 + 宇宙网公知结构 | 搜 M16/M31/KBC 能飞到层 |
| 4 英雄深空 | 3–4 | 创生之柱；Sgr A* | 近景+真假旁白 |
| 5 科学官 v1 | 3 | 半身像+TTS+文字检索问答 | 「颜色是真的吗」答对 |
| 6 目录扩张 | 持续 | NGC/IC、Gaia LOD、MPC 子集、系外行星确认表 | 关于页公布快照条数 |
| 7 打磨 | 持续 | 五条精剪航线、分享 URL | 3 分钟完航 |

首发：**0–5 + Messier 全表 + 宇宙网公知结构 + 太阳系**。NGC 全表与 Gaia LOD 放 1.1。

---

## 9. 首发成功标准

1. 3 分钟：地球 → 外层 → 回太阳系。
2. 八层定位场景可进，HUD 正确。
3. Messier 110 可搜可定位；创生之柱、KBC、巨引源、地球山河、地球剖面可到达。
4. 现象类型表无空类（每类至少范例+讲解卡）。
5. 科学官能讲当前条目并区分观测/可视化。
6. 关于页列出目录快照版本与「未接入」清单。

---

## 10. 范围变更规则

新增随口想起的天体：先入目录摄取（B），再评估是否升英雄（C）。  
不得打乱八层模型，不得把示意图升级成假地形。  
有争议结构可收录，必须标置信度。
