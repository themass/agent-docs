# Planet texture attribution

Textures in this directory are served locally so Three.js/WebGL can load them without cross-origin (CORS) restrictions.

## Solar System Scope (CC BY 4.0)

Most files (`2k_*.jpg`, `2k_saturn_ring_alpha.png`) are from:

- https://www.solarsystemscope.com/textures/
- License: Creative Commons Attribution 4.0 International

## three.js examples

- `moon_1024.jpg` — used as Pluto placeholder until a New Horizons mosaic is baked in.

## Re-download

```bash
bash scripts/download_textures.sh
```
