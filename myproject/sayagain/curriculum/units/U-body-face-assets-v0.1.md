# U-body-face-v0.1 Milo 与课程资产清单

> 状态：资产 brief 初稿。它定义教学所需资产，不等同最终美术稿或 3D 技术选型。

## 1. Milo 角色 brief

### 角色定位

Milo 是一个原创、风格化 3D 动漫探索伙伴。它好奇、耐心、愿意和孩子一起找答案；错误时不会失望或嘲笑。Milo 的外形应能被儿童接受，也不能让青少年/成人体验显得像幼儿园玩具。

### 视觉要求

- 轮廓清楚，手指/指向方向在小屏上可辨；
- 表情简洁，情绪不依赖夸张哭泣或失败脸；
- 角色服装和配色不要绑定具体民族、性别或现实学校制服；
- 身体部位示范使用安全、尊重、非羞辱性镜头；
- 可在实时 3D、预渲染动画、静态图三种层级降级；
- 角色不是答案本身：测验阶段可显示陪伴头像，但不得指向正确选项。

## 2. 必需动作资产

| Asset ID | 动作 | 使用节点 | 教学/装饰 | 验收要求 |
|---|---|---|---|---|
| `milo.idle.listen` | 等待/倾听 | 题目等待、音频播放 | 教学状态 | 不遮挡内容，循环自然 |
| `milo.point.eye` | 指向眼睛 | L1 建义 | 教学 | 指向清晰，镜头不泄漏到其他部位 |
| `milo.point.ear` | 指向耳朵 | L1 建义 | 教学 | 与听的手势可组合 |
| `milo.point.nose` | 指向鼻子 | L1 建义、提示 | 教学 | 手指与鼻子关系清楚 |
| `milo.point.mouth` | 指向嘴巴 | L1 建义 | 教学 | 不使用夸张口型替代音频 |
| `milo.demonstrate.touch` | 摸鼻子 | L2 示范 | 教学 | 全身/半身构图动作易懂 |
| `milo.demonstrate.open-mouth` | 张嘴 | L2 示范 | 教学 | 安全、短时、不过度夸张 |

## 3. 镜头与场景

### L1 场景：镜子前的脸

- 画面：Milo 与简洁镜面/头像卡；
- 目标：让局部身体词有整体脸部参照；
- P0：目标部位可用较明显轮廓，但不可覆盖无提示测验；
- P1：从带轮廓逐步到普通脸部图；
- P2/P3 后续：可切换至运动、健康或看医生场景。

### L2 场景：准备一张“会做动作的脸”

- 画面：Milo 在安全、非真实医疗的室内场景；
- 目标：承载 `touch`, `open`, `close` 指令；
- 任务：完成 1–2 条指令，不需要摄像头；
- 亲子：家长可以播放指令，孩子做或点图。

## 4. 音频资产

每个目标至少需要：

```text
word_en-US-or-target-locale
phrase_en-US-or-target-locale
slow_variant（如教研认为必要）
example_or_instruction
```

音频要求：

- 目标口音、录音人身份、许可和版本可追踪；
- 词和句之间有清楚停顿；
- 播放、暂停、重播、失败和缺失状态明确；
- 文本字幕可作为无音频替代；
- 不以角色口型是否同步来判断孩子发音。

## 5. UI 资产与可访问性

- 五张清晰脸部局部图/热点图；
- 每个指令至少两张动作对比图；
- 所有目标图有可读屏描述，如“眼睛，eye”；
- 颜色不能是唯一差异；
- 触控热点至少 48dp，身体部位太小则提供列表选择；
- 字体放大后，Milo 可缩小但词和题目不能被遮挡；
- 动画关闭/减少动效时，教学信息仍完整。

## 6. 降级矩阵

| 能力/资产 | 首选 | 降级 1 | 降级 2 | 对证据的影响 |
|---|---|---|---|---|
| 角色 | 轻量 3D 动作 | 预渲染短动画 | 静态图+动作图 | 不改变目标；记录呈现版本 |
| 指向 | 动作指向 | 轮廓/热点提示 | 图文说明 | 若提示暴露答案，不算无提示 |
| 音频 | 本地目标音频 | 在线重试 | 文本/字幕 | 无音频时不记录听辨成功 |
| 动作执行 | 孩子真实做 | 点正确动作图 | 点身体部位 | 点图不等同真实执行 |
| 口头尝试 | 麦克风仅记录参与（后续） | 家长观察 | 跳过 | 不自动判定发音准确 |

## 7. 资产交付与审校字段

每个资产必须带：

```text
asset_id
asset_type
content_ids / goal_ids
experience_bands
locale
source
license_or_ownership
version
fallback
review_status
```

审校角色至少包括：

- 英语语言审校；
- 儿童适龄/教学审校；
- 插画/3D 资产质量审校；
- 可访问性检查；
- 版权与授权记录。

## 8. 资产验收

- [ ] Milo 的示范动作清晰、短、可暂停；
- [ ] 测验阶段没有持续指向答案；
- [ ] 角色不遮挡题目、选项、返回和播放按钮；
- [ ] 静态/预渲染降级仍能完成非口语核心学习；
- [ ] 缺失音频不会伪造听辨证据；
- [ ] 图像、字幕、音频和内容 ID 一致；
- [ ] 所有资产来源和许可可追溯。
