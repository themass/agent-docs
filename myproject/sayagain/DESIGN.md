# SayAgain 视觉设计规范 v0.1

> **状态：首发原型配套视觉方向，待角色和品牌确认后冻结**  
> 日期：2026-10-13

## 1. 设计目标

SayAgain 的界面应让用户感到“轻松、清楚、愿意再试一次”，而不是像考试工具或幼儿游戏。

设计原则：

1. **内容优先**：单词、含义、例句和选项永远高于装饰。
2. **低压力反馈**：答错是学习路径的一部分，不用羞辱和惩罚。
3. **数字人是教练**：在需要解释、指向、鼓励时出现；不抢占题目。
4. **可离线完成**：离线状态不破坏核心学习流程。
5. **成人友好**：明亮但不幼稚，角色可爱但不喧宾夺主。

## 2. 品牌方向

工作关键词：**明亮、温和、专注、陪伴、清晰**。

暂定视觉语言：

- 基础背景：暖白/浅奶油色。
- 主色：偏蓝的清爽紫蓝，用于主行动和学习进度。
- 辅助色：薄荷绿表示掌握，琥珀色表示提示，珊瑚色表示需要再看一眼。
- 大面积留白，卡片少阴影，减少“儿童教育产品”的玩具感。

## 3. Design Tokens

### 3.1 色彩

```text
color.background        #FFFDF8  暖白背景
color.surface            #FFFFFF  卡片/内容面
color.surface-muted      #F5F3EE  次级区域
color.text-primary       #202124  主要文字
color.text-secondary     #686A73  解释文字
color.text-disabled      #A7A8AE  禁用文字
color.brand              #5B5BD6  主按钮/进度/链接
color.brand-pressed      #4747B5  按压态
color.brand-soft         #E9E8FF  主色浅底
color.success            #2C9B72  答对/完成
color.success-soft       #E4F6EF  答对背景
color.hint               #D58B2A  提示
color.hint-soft          #FFF2D9  提示背景
color.error              #C85A58  需要重看
color.error-soft         #FDEAE8  错误背景
color.border             #E7E5DF  边框/分隔线
```

颜色不可作为唯一状态信息；正确/错误必须同时配合图标和文字。

### 3.2 字体层级

以 Android 默认无衬线字体为首发默认，避免引入过多字体包：

```text
Display:  32sp / 40sp / 700  关键单词、完成数字
Title:    24sp / 32sp / 700  页面标题
Headline: 20sp / 28sp / 600  题干、卡片标题
Body:     16sp / 24sp / 400  正文、选项
Label:    14sp / 20sp / 600  次级按钮、标签
Caption:  12sp / 16sp / 400  辅助说明
```

- 英文单词使用较大字号和足够字距。
- 中文解释至少 16sp。
- 不在一个卡片内同时使用超过 4 个字号层级。

### 3.3 间距

基础单位 4dp，优先使用：

```text
space-1: 4dp
space-2: 8dp
space-3: 12dp
space-4: 16dp
space-5: 20dp
space-6: 24dp
space-8: 32dp
space-10: 40dp
```

页面水平边距：手机默认 20dp；小屏最低 16dp。

### 3.4 圆角与高度

```text
radius-sm: 8dp
radius-md: 12dp
radius-lg: 20dp
radius-pill: 999dp
button-height: 52dp
compact-button-height: 44dp
minimum-touch-target: 48dp
```

主按钮采用 12–16dp 圆角，不使用过度胶囊化，避免界面像游戏商城。

## 4. 页面布局规则

### 4.1 学习页

竖屏手机的内容优先顺序：

1. 顶部返回和进度。
2. 数字人/图片辅助区域。
3. 目标词或题干。
4. 选项/输入区域。
5. 提示和主行动。

数字人高度建议不超过可视区域的 26%；内容不足时可以缩小为头像和气泡。

### 4.2 首页

首页只保留一个主行动：开始/继续今日学习。复习使用第二层级行动，不和今日学习争夺注意力。

### 4.3 反馈

反馈面板应采用同一位置、同一结构：

- 状态图标
- 一句结论
- 目标词/搭配复现
- 简短解释
- 下一步按钮

## 5. 组件视觉约定

### PrimaryButton

- 主色背景、白色文字。
- 高度 52dp，宽度默认填满内容区。
- 按压变深，加载时保留按钮宽度并显示进度。
- 禁用时使用灰色背景和明确禁用原因。

### AnswerOption

- 白色背景 + 1dp 边框。
- 默认 56dp 高，选项之间 12dp 间距。
- 选中但未提交：主色边框 + 浅色底。
- 答对：绿色边框、勾选图标和“答对了”。
- 答错：珊瑚色边框、提示图标和解释；不摇晃整个页面。

### DigitalTutorCard

- 背景使用 `brand-soft` 或暖白，不使用高饱和渐变。
- 角色插画最多占卡片 40% 宽度。
- 气泡文字限制在 2–3 行，长文进入详情而不是塞进气泡。

### ProgressIndicator

- 细进度条高度 6–8dp。
- 同时显示“3/10”，不只依赖进度条。
- 离开保存时不显示强制阻塞式全屏提示。

## 6. 动效规范

动效服务于理解，不服务于刺激：

```text
micro feedback: 120–180ms
card transition: 180–240ms
page transition: 240–300ms
celebration: <= 800ms
```

- 答对：轻微缩放/点头/勾选出现。
- 答错：内容高亮和提示出现，不使用强烈震动。
- 页面切换：淡入或水平滑动，支持减少动效设置。
- 所有关键内容即使关闭动效也必须完整可用。

## 7. 可访问性

- 触控目标不小于 48dp。
- 正文与背景达到可读对比度；不要用浅灰作为主要文字。
- TalkBack 顺序：页面标题 → 进度 → 题干/单词 → 音频按钮 → 选项 → 提示 → 主按钮。
- 动画角色使用 `contentDescription` 描述当前教学作用，而非“一个可爱的角色”。
- 音频按钮提供“播放单词发音”“播放例句发音”等明确标签。
- 不用颜色单独表达答对/答错。
- 支持系统字体放大；放大后数字人可以缩小，题干和选项不截断。

## 8. Android Material 3 映射建议

这是视觉映射，不是最终技术选型：

- `Scaffold`：承载首页和底部导航。
- `NavigationBar`：今天、词包、我的。
- `TopAppBar`：学习页返回和进度。
- `Card`：今日任务、数字人提示、复习摘要。
- `Button` / `OutlinedButton`：主行动和次行动。
- `LinearProgressIndicator`：学习进度。
- `Snackbar`：非阻塞保存/联网提示。
- `ModalBottomSheet`：提示详情、音频或词条补充信息。

## 9. 角色和插画方向

角色资产首发建议准备 5 个基础状态：

1. neutral：等待/讲解
2. pointing：指向图片或目标对象
3. hint：提示
4. encouraging：鼓励再试
5. celebrating：完成/答对

首发不需要复杂骨骼动画；可以先使用静态插画 + 少量位移/缩放/眨眼，验证产品闭环后再决定 Lottie、Rive 或其他动画方案。

## 10. 视觉验收清单

- [ ] 用户打开首页后 3 秒内能找到今日主行动。
- [ ] 单词和题干在视觉上优先于数字人。
- [ ] 答错时用户知道下一步是什么。
- [ ] 正确、错误、提示状态不靠颜色单独区分。
- [ ] 设备宽度 320dp 时无横向滚动和按钮截断。
- [ ] 字体放大后选项仍可点击、文字可换行。
- [ ] TalkBack 能读出所有关键学习内容。
- [ ] 离线提示不遮挡学习内容。
