# SayAgain 教学产品实施计划 v0.1

日期：2026-10-14。状态：教学产品建设计划；技术开发排期尚未冻结。

## 1. 总体建设路径

```text
方法论与总纲
  → 两个试学单元
  → 内容/活动/证据审校
  → 基于真实课程的高保真原型
  → 少量家庭试学
  → 冻结 MVP
  → 技术选型与方案
  → 开发、内容制作、测试、内测
```

## 2. 工作包与责任

| 阶段 | 我负责的初稿/推进 | 产品方负责的判断/资源 | 外部必需评审 |
|---|---|---|---|
| W0 教学总纲 | 能力分层、课程结构、方法和活动契约 | 产品边界、品牌方向、优先级 | 英语教研/儿童教育意见 |
| W1 A0 我的脸 | 教案、内容对象、题型、复习和资产清单 | 体验是否符合产品意图 | 英语语言、适龄与素材审校 |
| W2 B1 找一找动物 | 对比型教案，验证可复用性 | 确认动物园/人与动物关系表达 | 英语/内容安全审校 |
| W3 原型 v0.2 | 基于真实脚本的流程与状态设计 | 视觉、角色、亲子体验确认 | 儿童可用性复核 |
| W4 家庭试学 | 试学脚本、观察表、结果归纳 | 招募 5–8 个目标家庭或确认渠道 | 必要时研究/隐私建议 |
| W5 技术方案 | 平台、内容包、3D、数据、测试方案 | 成本、团队、上线地区决策 | 安全、隐私、架构评审 |

## 3. 立即开始：W1《我的脸》

### 输入

- 教学产品总纲与能力分层 v0.2；
- 课程内容路线图 v0.1；
- 单元设计模板、活动模板；
- P0/P1 体验带假设。

### 输出

```text
curriculum/units/U-body-face-v0.1.md
curriculum/units/U-body-face-content-v0.1.md
curriculum/units/U-body-face-assets-v0.1.md
```

### 完成定义

- 两节短课均具备：目标、内容、活动、提示、错误恢复、证据、退出恢复；
- 至少一种无提示听辨活动和一种指令理解活动；
- 亲子任务可跳过且不需要家长英语能力；
- Milo 的动作能清楚区分教学示范和测验；
- 复习不只重放同一题；
- 语言、教学、素材审校待办已显式列出；
- 不将“说一说”写成已实现的发音评测。

## 4. W2 的验真原则

B1《找一找动物》不能复制《我的脸》的动作套路。若框架只能支持“指身体部位”，说明它不可持续；如果它也能处理场景探索、听辨、动物特征和人与动物园的关系，才可以进入原型与技术方案。

## 5. 关键依赖与暂缓项

| 项目 | 现在是否推进 | 原因 |
|---|---|---|
| 课程脚本与内容审校 | 是 | 是所有后续工作的输入 |
| Milo 角色概念 brief | 可并行做方向稿 | 需依据课程动作与体验带确定 |
| HTML/高保真原型重构 | 等 W1 首稿后 | 原型必须演示真实教学脚本 |
| Android/iOS 技术选型 | 暂缓 | 3D/内容/账号复杂度尚不确定 |
| 开源项目源码集成 | 暂缓 | 先确定教学与内容/证据模型 |
| 亲子/班级/公开 PK | 分层规划，暂不做 | 权限、安全、身份和合规未定义 |
