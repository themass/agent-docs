# SayAgain 教学产品总纲与能力分层 v0.2

> 状态：战略与教研设计基线，待英语教研与儿童安全评审。  
> 日期：2026-10-14  
> 取代范围：本文件补充并优先于早期“仅 7–9 岁首发用户”工作假设；不代表首发同时交付所有年龄段课程。

## 1. 产品定位

SayAgain 是面向**全年龄段英语学习者**的主题化英语教学产品：儿童可以在亲子陪伴或自主闯关中学习，青少年和成人可以沿同一能力地图进行更高难度的主题、表达、阅读和写作学习。

它不是一套按年龄强制推进的词卡库，而是：

```text
统一能力地图
  + 主题课程内容库
  + 按年龄、能力、学习目标适配的教学路径
  + 可验证的学习证据
  + 亲子/同伴/班级的受控互动
```

## 2. 年龄不是课程等级，能力才是

同为 10 岁的孩子，英语起点可能相差很大；同为 A1 学习者，儿童和成人需要的情境、解释与激励也不同。因此使用两组标签：

- **能力层 C0–C4**：决定语言与任务难度；
- **学习者体验带 P0–P3**：决定叙事、解释、界面、陪伴和社交权限。

### 2.1 能力层（内容与目标）

| 层级 | 语言能力工作定义 | 典型任务 | 当前状态 |
|---|---|---|---|
| C0 | 借助对象、动作和母语支架建立词义 | 听词找图、跟随单步指令 | 首发核心 |
| C1 | 在低支持下理解常用词、短语、短指令 | 听音找对象、完成搭配 | 首发核心 |
| C2 | 在简单句与熟悉情境中理解和受控使用 | 情境选择、简短回应、读词句 | 后续扩展 |
| C3 | 在熟悉主题中完成短对话、阅读和书面表达 | 问答、读段、写句 | 后续扩展 |
| C4 | 处理更复杂主题、文本、表达与任务 | 阅读、写作、讨论、项目 | 长期路线 |

C0–C4 是内部课程设计分层，不是国际考试成绩，也不能直接等同 CEFR 等级。

### 2.2 体验带（产品与教学支持）

| 体验带 | 建议人群 | 教学与产品设计 |
|---|---|---|
| P0 亲子启蒙 | 学龄前至小学低年级，或任何需要高支持的初学者 | 亲子陪伴、动作任务、短回合、母语支架、无开放社交 |
| P1 儿童自主 | 小学生 | 主题闯关、角色带学、选择性亲子任务、受控挑战 |
| P2 青少年成长 | 中学生 | 更真实主题、目标规划、读写与表达任务、班级/熟人协作 |
| P3 成人自主 | 大学生及成人 | 目标导向路线、情境任务、效率与可迁移表达、社群由单独规则管理 |

同一 C0 身体主题可以在 P0 用“指一指、做一做”，在 P3 用“健康、看医生、身体描述”呈现。内容对象可以复用，课程脚本、表达目标和体验必须不同。

## 3. 长期能力大纲：听、说、读、写、练与学习调节

### 3.1 五项语言能力 + 学习调节

| 维度 | 长期目标 | C0–C1 首发处理 | 后续扩展 |
|---|---|---|---|
| 听 | 从词/指令理解到对话与文本信息提取 | 听词找对象、听短指令 | 对话、故事、讲座类文本 |
| 说 | 从模仿与回应到描述、互动、表达观点 | 鼓励跟说与短回应；不自动判音准 | 语音反馈、对话、展示 |
| 读 | 从词形识别到段落与多文本理解 | 可选图词匹配；不以拼写为先决 | 分级阅读、信息检索、批判阅读 |
| 写 | 从词形/句型到段落与任务写作 | 不作为 C0 达标目标 | 拼写、写句、短文、改写 |
| 用 | 在情境中选择、组合和迁移语言 | 搭配、指令、微任务 | 项目、真实交际与跨主题迁移 |
| 学习调节 | 知道自己是否需要提示、复习或帮助 | “还想练 / 准备继续” | 目标、计划、自评与策略 |

“练”不是第六种语言能力；它是让听、说、读、写、用得到重复、反馈和迁移的过程。

### 3.2 四类课程机会检查

每个完整主题包在课程层面检查是否提供以下机会，避免产品沦为刷词：

```text
意义导向输入：听/读懂可理解内容
意义导向输出：说/写/回应有意义表达
语言形式学习：词义、语音、词形、搭配、句型
熟练使用：已学内容在低压力条件下重复使用
```

首发 C0–C1 内容会明显偏向输入与语言形式；这不是缺陷，但必须在课程地图上诚实呈现，后续以亲子任务、口头尝试和情境任务增加输出机会。

## 4. SayAgain 教学原则

### 原则 A：先有可理解意义，再要求记忆

先让学习者看见对象、情境、动作或任务目的，再呈现词、声音和必要解释。禁止把长词表作为一个主题课的开场。

### 原则 B：多通道必须同向，不是素材堆叠

声音、画面、文字、动作和数字人指向同一个教学目标。无关特效、角色对白和奖励不能抢占注意力。

### 原则 C：支架逐步撤除

```text
完整示范 → 引导选择 → 部分提示 → 无提示提取 → 换情境再遇
```

同一数字人动作在示范阶段可提供答案；在无提示测验阶段不能继续泄露答案。

### 原则 D：主动提取早于答案揭示

孩子先尝试，再看答案；提示后正确、看答案后继续、无提示正确分别记录。复习不仅复制原题，而是改变图、顺序、感知通道或情境。

### 原则 E：使用最小可用语言块

不要从孤词直接跳到自由造句。每个词以适龄的短语、指令或短句进入使用：

```text
eye → my eye → close your eyes → My eyes are ...（后续）
```

### 原则 F：快乐来自可掌握、可选择、可看到成长

角色、地图、徽章、亲子、PK 都必须降低进入门槛或增加有意义重复，不能以速度、羞辱性失败或无限奖励取代理解。

### 原则 G：证据诚实

系统只声称自己真正观察到的内容。没有自动语音评测就不能说“发音正确”；没有摄像头或家长观察就不能说“完成了动作”。

## 5. 数字人教学角色：Milo

### 5.1 角色定位

Milo 是原创、风格化 3D 动漫学习伙伴：好奇、耐心、爱探索、不会嘲笑错误。它不是拟人教师的替代，也不是只卖萌的宠物。

角色视觉方向（后续进入角色设计 brief）：

```text
名字：Milo（可本地化/可更名）
年龄感：不明确的人类年龄；儿童愿意亲近、青少年不感到幼稚
物种/外形：原创的小型探索伙伴，避免依附具体民族、性别或真人外貌
核心特征：可清楚完成指向、听、观察、拿道具、鼓励、庆祝
视觉层级：风格化 3D，支持实时/预渲染/静态降级
```

### 5.2 教学职责边界

| Milo 可以做 | Milo 不做 |
|---|---|
| 指向、示范动作、建立场景、给最小提示、鼓励、总结 | 伪装成真人老师、夸张口型冒充发音评测、替孩子回答 |
| 在动物园观察动物、在身体主题指向部位 | 测验阶段持续指向正确答案 |
| 引导亲子轮流互动 | 用失望、嘲笑或惩罚制造压力 |

## 6. 互动与 PK 的通用模型

产品应支持亲子、班级和其他用户，但不是“所有用户立即互相公开对战”。关系、权限和活动模式分开建模。

### 6.1 关系类型

```text
个人学习者
家庭组（监护人 + 儿童）
熟人组（双方同意）
班级组（教师/组织者管理）
开放社区（仅在成人、审核、地区合规另行成立后考虑）
```

### 6.2 活动类型

| 类型 | 首发状态 | 规则 |
|---|---|---|
| 个人闯关 | P0 | 以学习目标和复习为核心 |
| 亲子共学 | P0 可选 | 家长可参与、不替孩子答题、可跳过 |
| 亲子挑战 | P1 | 同主题短回合，双方自愿，家长可关闭 |
| 班级任务 | P2 | 教师/组织者身份、成员可见性、作业与反馈另设方案 |
| 熟人挑战 | P2 | 双方确认或邀请关系，异步优先 |
| 公开匹配 PK | 未承诺 | 涉及儿童保护、审核、作弊、匹配公平和地区法规，需独立立项 |

### 6.3 PK 的教学契约

PK 只可使用已学或已解锁的内容；结果必须与能力证据分离。主分由正确率、提示使用、完成复习和任务质量构成，速度仅能是可选的、低权重的同分参考。无自由聊天、公开搜索、羞辱性排名或因失败扣除已获得学习状态。

## 7. 首发与长期的范围边界

### P0：证明核心教学闭环

- 体验带 P0/P1 为重点，但内容对象可复用到其他体验带；
- 主题路线；
- 两个对比鲜明的主题样例：人体与动物园；
- 每个主题先完成一个正式可试学单元；
- Milo 教学动作与降级策略；
- 离线、恢复、学习证据和家长可理解反馈；
- 可选的亲子一分钟任务。

### P1：证明内容和亲子扩展

- 扩展两个主题包；
- 年龄/体验带变体；
- 家长成长记录；
- 家庭组与亲子挑战。

### P2：证明组织化学习与社交扩展

- 班级组织能力；
- 熟人异步挑战；
- 青少年课程路径；
- 初步读写任务；
- 内容来源、审核、账号与隐私方案完善。

P0 不等于完整全年龄段上线；它是为全年龄段产品建立可复用内容和能力底座。

## 8. 后续评审门槛

进入首发技术方案前，需要确认：

- [ ] 两个主题单元均能用“目标—内容—活动—证据”链路描述；
- [ ] P0/P1 的课程体验不会互相矛盾；
- [ ] 亲子参与是鼓励而非强制；
- [ ] Milo 在示范与测验中的信息边界可实现；
- [ ] PK 的长期需求已转化为关系/权限/活动模型，而不是一个按钮；
- [ ] 儿童账号、家长授权、班级组织和公开匹配已拆成独立后续模块。
