# SayAgain 教学产品框架与课程大纲 v0.1

日期：2026-10-13  
状态：教学框架评审稿；不是完整课库、教研审定结果或效果验证报告。

## 0. 决策与文档地位

已确认：教学产品；亲子家庭与小学生；Android/iOS 客户端；首发只开放主题学词；原创风格化 3D 动漫伙伴；先以身体部位主题验证核心教学流程。

待验证工作假设：首轮试学优先选择 7–9 岁、英语零基础至初级孩子与家长；不意味着其他小学生被排除。中文解释、短时学习、家长不必懂英语。年龄与英语能力分开记录，不以年级推断英语水平。

本框架用于统一后续 PRD、课程脚本、原型和技术方案。历史页面、题型或奖励规则如与本框架冲突，应先修订；不直接沿用。

> 产品目标 → 能力目标 → 内容大纲 → 教学方法 → 学习活动 → 证据与反馈。
> 形式可以换，目标与证据不能丢。

## 1. 四层框架：目标、内容、方法、形式

| 层 | 定义 | 样例 | 必须输出 |
|---|---|---|---|
| 目标层 | 孩子在什么条件下能做什么 | 不显示文字，听到 nose 后选择鼻子 | 可观察的能力描述与达标证据 |
| 内容层 | 为目标提供哪些语言与情境 | nose、touch your nose、脸部图 | 内容对象、关系、场景、先修条件 |
| 方法层 | 怎么从不会走到会 | 示范、引导、撤除提示、回忆、延迟复习 | 教学序列与支架规则 |
| 形式层 | 用户怎样参与 | 数字人指向、闪卡、找一找、亲子任务、PK | 活动模板、输入、反馈、证据边界 |

增加一个主题，主要扩展内容；增加一种玩法，主要扩展活动模板；两者通过目标 ID 与内容 ID 连接，不相互复制。

## 2. 教学目标与能力地图

### 2.1 长期目标

在熟悉生活情境中，逐步发展理解、表达、互动与自主复习能力。产品不是全学科教材的替代，也不以累计词数作为综合英语等级证明。

| 能力 ID | 能力 | 初阶目标 | 后续目标 | 首发处理 |
|---|---|---|---|---|
| listen-word | 听懂词与搭配 | 听词找对象 | 听短句、对话获取信息 | 正式训练并记录 |
| listen-instruction | 听懂指令 | 理解 touch your nose | 理解多步骤任务 | 练习选择可测理解；实际执行需家长确认 |
| speak-word | 口头表达 | 模仿、尝试说出目标词 | 短句描述、对话回应 | 鼓励尝试，不作自动正确判定 |
| read-word | 词形识别 | 把词形与对象匹配 | 读句、读短篇 | 作为适龄分支；初阶不强制拼写 |
| write-word | 拼写与书面表达 | 后续拼写高频词 | 句子、短段落 | 首发不设达标承诺 |
| use-chunk | 搭配使用 | 理解动作搭配 | 在新情境选用表达 | 受控选择、补全可测；口头使用单独标记 |
| interact | 互动任务 | 与家长轮流指认 | 情境问答、合作任务 | 亲子延伸，不等同独立能力证明 |
| learn-self | 学习调节 | 会请求提示、知道需复习 | 自评与学习计划 | 简单“还想练/准备继续”反馈 |

“练”是跨能力的学习过程，不是与听说读写并列的一项语言能力。语法先在短语/句型中承担作用，后续再形成显性语法课程；阅读、写作仍在长期蓝图中，首发不假装覆盖。

### 2.2 能力目标标准格式

```text
在【情境】中，使用【允许的支持】，孩子能【可观察行为】，
以【何种证据】判断，达到【试行门槛】，并明确【不能推断的能力】。
```

示例 G-face-listen：不给英文/中文文字，播放 eye / ear / nose / mouth，孩子能选中正确部位；每词至少获得两个不同题序下的无提示正确记录，其中至少一个来自跨日复习。此门槛为试行规则，不是已验证标准；不能据此推断会口头说出或拼写。

### 2.3 掌握不是单一分数

按“具体词义/表达 × 能力方向”记录：未接触 → 已接触 → 支持下完成 → 当日独立完成 → 延迟巩固 → 新情境应用。

- 听辨正确不等于口头表达正确；
- 选择正确不等于主动回忆或实际做出了动作；
- 点击“说过了”只记录参与，不记录发音准确；
- 用过提示、看过答案后完成，不算独立成功；
- 家长观察证据与系统答题证据分开，不合并为同一可靠程度；
- 徽章、星星、胜负属于体验反馈，不进入能力评分。

## 3. 内容大纲：双轴，而不是一条年龄流水线

### 3.1 轴 A：主题领域

以下是可扩展目录，不是全部首发承诺；主题编号不对应 CEFR 等级。

| 主题 | 单元样例 | 情境任务 | 适合的方法/形式 |
|---|---|---|---|
| 我的身体 | 我的脸、身体、动作与感受 | 听指令找部位 | 数字人示范、指认、亲子动作 |
| 我的家 | 房间、家具、物品 | 找到并描述物品 | 场景探索、闪卡、分类 |
| 食物与生活 | 食物、饮料、用餐 | 表达想要什么 | 情境选择、简短问答 |
| 动物园与自然 | 动物、特征、天气 | 找动物、辨特征 | 听音找图、观察比较 |
| 学校与朋友 | 文具、课堂、兴趣 | 理解课堂指令 | 合作任务、搭配练习 |
| 职业与社区 | 职业、工具、地点 | 把人物与工具匹配 | 道具示范、情境匹配 |
| 汽车与出行 | 部件、交通、方向 | 理解简单出行信息 | 部件热点、路线任务 |
| 国家与旅行 | 国家、国籍、地点 | 简单介绍与旅行表达 | 地图探索、角色任务 |

### 3.2 轴 B：能力难度

- C0：听声音、看对象、模仿动作；需要充分支持。
- C1：撤去翻译，听词找图、词形匹配、理解一条指令。
- C2：在短语和简单句中理解/选择，迁移到另一张图或另一个对象。
- C3（后续）：简短口头互动、读句、初步拼写。
- C4（后续）：短篇阅读、写句与多轮情境任务。

C0–C4 是内部活动复杂度标签，不是正式语言等级。每个主题可以有多种难度，孩子不必学完身体才能探索动物；先修条件应是语言能力或内容依赖，而不是为了地图整齐而强制锁主题。

### 3.3 多种课程入口

主题、年级、教材、考试是同一内容库的不同编排视图。课程路线可以指定不同先后顺序、释义、任务和难度，但共享稳定内容 ID 与能力证据。

- 年级必须绑定地区、课程标准和学期，不能把“1 年级”当作全球统一难度。
- 教材必须注明版本、来源与授权状态；未获适当使用权不复制原文/插图/音频。
- 考试路线使用经审阅的能力映射，不因某一词出现就声称已达某等级。
- 同一拼写的不同词义分开；词族、词形变化、短语与句型显式关联。

## 4. 教学思想：五环是产品编排规则，不是自创法已被证明有效

### 4.1 核心序列

```text
情境引入 → 多通道建义 → 支架渐退与主动提取 → 情境使用 → 延迟再遇
```

| 环节 | 设计规则 | 禁止做法 |
|---|---|---|
| 情境引入 | 先给可理解的对象、目的和短语音 | 一开始堆释义、音标与长说明 |
| 多通道建义 | 声音、画面、动作相互对应；中文可作为必要支架 | 把“多媒体越多越好”当原则；无关动画抢注意力 |
| 支架渐退 | 示范后给引导练习，再撤去提示、换题序 | 同一答案连续重复后就宣称掌握 |
| 情境使用 | 用已学表达完成指令、选择、亲子任务 | 一次从词义跳到开放造句、强制发音评分 |
| 延迟再遇 | 跨日换方向、换对象复习；失败回到建义 | 因输掉游戏直接降低能力评级或无限加题 |

### 4.2 听说读写的分配

初阶以听懂与具体语义为主；孩子可先看图听音，再逐步引入英文词形。说话可模仿、可自愿尝试，不能用选择题冒充口语评测。读词进入适龄支线；拼写与写句需要单独教学设计，不由“学过这个词”自动解锁。

初步活动时长建议每轮 5–8 分钟，可暂停；单次内容量按完成质量调节，不为了每日数量硬塞新词。此时间与数量需试学验证，不是教育效果结论。

### 4.3 纠错与复习的试行规则

- 首次错：中性说明“我们再看看”，提供最小必要线索；
- 再错：重播示范并解释，稍后换方向再遇；
- 连续困难：减少选项/减少内容，让孩子正常退出，不无限重试；
- 当日重试不代替跨日证据；
- 试行复习窗口：次日、约第 3 日、约第 7 日；表现决定提前或延后，需试学调优；
- 多次失败先检查内容歧义、图片/音频是否清楚，不只归因孩子能力；
- 积压复习分批处理，允许孩子选择短回合。

## 5. 两套可持续扩展框架

### 5.1 内容框架

```text
路线 Route → 主题 Theme → 单元 Unit → 课 Lesson → 活动实例
                                    │             │
                                    └─目标 Goal ←─┘
内容对象 ContentItem ←──活动实例──→ 活动模板 ActivityTemplate
    │                                        │
释义/音频/图片/短语/句型/先修关联             互动/反馈/证据契约
```

必要对象：

| 对象 | 必备字段 |
|---|---|
| Goal | ID、能力、条件、可观察行为、达标规则、证据边界、版本 |
| ContentItem | ID、类型、具体词义、表达、音频、图/场景、例句、关联、来源/授权、版本 |
| Unit | 目标、先修、内容清单、新旧内容比例、完成规则、补救路径 |
| Lesson | 场景、目标、活动序列、支架序列、退出恢复点、亲子延伸 |
| ActivityInstance | 模板 ID、目标 ID、内容 ID、难度、支持、答案/判定、素材配置 |
| Evidence | 目标/内容/活动版本、能力方向、提示/答案暴露、结果、来源、日期、尝试类型 |

正式资产发布前必须经语言审校、教学审校和素材适配检查；不使用未经审校的 AI 批量生成课程。

### 5.2 教学形式框架（活动库）

| 活动 ID | 形式 | 对应目标 | 可记录的证据 | 不能推断 |
|---|---|---|---|---|
| tutor-demonstrate | 数字人示范/指向 | 建义、示范指令 | 浏览、播放、参与 | 理解、掌握 |
| flashcard-recall | 闪卡回忆后揭示 | 词义回忆、复习 | 自评或客观作答，分开记录 | 点击“会”即掌握 |
| audio-hotspot | 听音点部位/对象 | 听辨 | 未提示选择结果 | 发音能力、真实身体动作 |
| picture-word | 图词匹配 | 词形识别 | 无提示匹配 | 听辨、拼写 |
| instruction-choice | 指令选择 | 指令理解 | 选择正确场景 | 实际执行了指令 |
| chunk-completion | 搭配补全 | 受控搭配理解 | 补全/选择结果 | 自由表达 |
| speak-attempt | 模仿/说一说 | 开口参与 | 尝试完成或家长观察 | 自动发音准确性 |
| scene-mission | 微情境任务 | 理解与迁移 | 多步选择、任务结果 | 所有语言能力 |
| family-task | 亲子共学 | 情境使用、互动 | 家长可选确认、完成记录 | 独立自动评测 |
| friendly-challenge | 熟人挑战（后续） | 已学内容重复提取 | 每题独立证据与胜负分离 | 速度等于掌握 |

每个模板都需定义：适龄范围、支持等级、输入方式、反馈、失败恢复、可访问替代、退出行为、可测/不可测能力、隐私依赖。主题不应绑死某一种玩法。

### 5.3 数字人动作契约

语义动作：point(target)、demonstrate(action)、hint(target)、encourage、celebrate。内容配置指定目标与时间点，不把 eye 动作硬写进每个页面。

- eye 指向眼睛、ear 指向耳朵、nose 指向鼻子、mouth 指向嘴巴；
- 示范与测验分开：测验若继续指向正确部位，会泄露答案，不能算无提示；
- 不要求摄像头识别孩子动作，首发不采集身体影像；
- 3D 资产失败时可用明确标记的图像/文本降级，不声称已经实时 3D；
- 手机性能、触达、音频与动作同步在技术方案阶段验证。

## 6. 可执行样例：我的脸

单元 U-body-face。核心对象 eye / ear / nose / mouth / face；核心指令 touch your nose、open your mouth、close your eyes。eyes 与 eye 建立词形关联，不增加一个互不关联词条。建议拆成两个短课，再做单元任务，不一次全部塞入。

| 节点 | 孩子活动 | 目标/证据 |
|---|---|---|
| 开场 | Milo 带孩子照镜子，说明今天要找五官 | 建立学习目的，不计掌握 |
| 建义 | 指向 eye、播放音频，孩子可跟指/跟说 | 示范参与 |
| 引导练习 | 看指向，选正确词或图 | 支持下完成 |
| 听辨 | 移除文字与指向，播放 eye，在脸部图中点选 | listen-word 的独立证据 |
| 换对象 | 用另一位角色/图片听辨 | 初步迁移证据 |
| 搭配 | 学 touch your nose，撤去示范后选择正确动作图 | listen-instruction/use-chunk；不是动作执行证明 |
| 亲子延伸 | 家长播指令，孩子可做动作；可选反馈 | 家长观察，不和客观测试混记 |
| 延迟复习 | 次日混合 eye、ear 等听辨，换顺序与图片 | 保持证据 |

结束页区分：“今天认识了哪些”“无需提示能听懂哪些”“还需要复习哪些”“尝试说过哪些”。不可用固定 7 分、+20 能量或一次选择宣称整个单元都掌握。

## 7. 快乐学习与挑战框架

先保证听得懂、操作简单、失败可恢复，再用角色、任务与奖励增强愿意参与的感觉。主题任务服务于目标，奖励不替代目标。

- P0：个人核心教学活动；亲子任务作为可跳过延伸，不依赖家长全程在场。
- P1：亲子共学工具与成长记录；具体家庭管理范围另做 PRD。
- P2：家长许可下的熟人异步 PK；不是用户已确认的首发交付承诺。
- 挑战应复用已学内容和同难度题型；双方条件不同不做公平能力排名。
- 不以速度作为主要得分、不用生命值阻断学习、不因失败惩罚能力状态。
- 无自由聊天、无陌生人搜索；上线前单独完成儿童隐私、许可、地区法规和安全设计，此文不作法律结论。
- 胜负、参与度和能力证据独立；亲子任务不能强迫家长代答或替孩子获胜。

## 8. 内容与活动扩展规则

### 8.1 新增主题

1. 写 3–5 个可观察目标；确认适龄、先修、单元粒度。
2. 提交核心词/搭配/句型和素材来源，定义哪些旧内容要复现。
3. 复用活动库配置；只有现有活动确实不能测目标时才新增模板。
4. 做完整一个单元的脚本与小样，不先批量扩展词数。
5. 语言/教学/素材审校后试学；通过再扩展主题。

### 8.2 新增玩法

1. 说明它弥补哪个教学目标或参与障碍；只“更酷”不够。
2. 定义客观输入与证据边界；不能测时标为参与活动。
3. 至少用两个不同主题测试可复用性。
4. 检查是否泄露答案、误判能力、增加认知负担、引入隐私风险。
5. 与更简单的活动比较：是否改善目标完成而非只增加停留时长。

### 8.3 版本与质量

稳定 ID 不随文案变动；同一拼写不同词义不合并。影响答案、素材语义或目标的修改升版本；不能把旧版作答无条件迁移成新版掌握。儿童可理解的完成规则与内部证据规则一一对应。

## 9. 试学与验收

试行门槛不是研究证实值。先用小样本发现问题，不宣称显著提升或长期效果。

| 维度 | 需要观察 | 不合格信号 |
|---|---|---|
| 目标透明 | 家长知道学什么，孩子知道当前任务 | 只知道赚星星，不知道学的词 |
| 听辨 | 撤去文字/动作后是否能回答 | 依赖数字人泄露答案 |
| 延迟保持 | 次日、第 7 日同方向异题结果 | 当日连答高但换题/跨日低 |
| 内容质量 | 图片、音频、干扰项是否清楚 | 正确答案不唯一、图义冲突 |
| 支架 | 提示使用率、挫败、退出 | 一直错、无限重试、猜题过关 |
| 亲子成本 | 家长完成延伸是否方便 | 家长不在场就无法学习 |
| 趣味价值 | 自愿返回、主动尝试 | 仅奖励刺激，不增加学习证据 |

进入开发前至少满足：首发单元有目标—内容—活动—证据追踪；核心脚本审校；原型示范/测验不泄露答案；离线/退出/资产缺失可恢复。儿童隐私和发行地区另设上线门槛。

## 10. 当前缺口与建设顺序

本文件让教学框架有了结构，但不代表产品设计已全部完成。

1. 评审本框架与首轮试学人群假设；
2. 用模板完成《我的脸》正式教学脚本、内容清单和资产需求；
3. 补齐 PRD 的 Android/iOS、儿童/家长、课程/活动/证据范围；
4. 重新设计原型，落实真实指向与四词活动，删除伪数据和泄题；
5. 少量家庭试学，验证可理解性与延迟回忆；
6. 再锁定技术选型与实现、内容制作成本、测试和发布计划。

现有 HTML 仍是早期交互草稿：CSS 吉祥物不是已完成的 3D 数字人；仅 eye 示例不足以证明四词课程；按钮跳页不等于学习恢复、家长功能或复习调度已实现。

## 11. 教学依据与适用边界

- IES/WWC《Organizing Instruction and Study to Improve Student Learning》：间隔学习、图文/具体与抽象结合、利用测验促进学习。支持底层原则，不证明 SayAgain 的五环组合已有效。
  https://ies.ed.gov/ncee/wwc/PracticeGuide/1
- EEF《Oral language interventions》：词汇需结合有意义使用与互动。多数背景不是本产品中国儿童第二语言自学场景，不能直接搬用其效果量。
  https://educationendowmentfoundation.org.uk/education-evidence/teaching-learning-toolkit/oral-language-interventions/
- Council of Europe《CEFR Companion Volume》：以理解、产出、互动等通信活动组织能力描述，可用于后续映射，不是现成儿童课程、固定词表或考试认证。
  https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-companion-volume-and-its-language-versions

“五环主题学习”是产品编排名称，不包装成有独立实证的教育学流派；不同孩子可有不同支持需求，不按所谓视觉型/听觉型学习者强行分类。
