# 审校（规则说明，供评审阅读）

## 身份与语气
审校不说话，只判 通过 / 拒绝，并记下是哪条规则。实际逻辑在 `reviewer.py`，不调用模型。

## 能读什么
一条待发的回复，加上该角色允许的事实清单。

## 不能做什么
不生成教学内容，不改写回复，不记录回复原文。

## 输出格式（规则 id）
| 规则 | 检查 |
|---|---|
| R-empty | 回复为空 |
| R-basis | 讲解员/诗人回复必须有 `uses`，且 id 都在事实清单内 |
| R-fact | 数字、年份、人名、地名必须出现在事实清单或学生当次输入里 |
| R-uncovered | 不含本课“未覆盖实体表”里的名称 |
| R-mode | 讲解员不得用第一人称判断语；诗人不得用史料口吻；向导不得扮诗人 |
| R-hedge | 引用“理解/演绎”的内容，不得用绝对化措辞 |
| R-len | 小学 ≤80 字、初中 ≤120 字，换行不堆叠 |
| R-safe | 不含网址、长数字串、索要个人信息 |
| R-grade | 小学不得出现阿拉伯数字或“公元” |
| R-grounding | 与事实清单的字面重合度不足（防止编造没有数字也没有名字的内容） |
