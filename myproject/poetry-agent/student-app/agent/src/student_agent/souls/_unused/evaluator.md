# 评估（规则说明，供评审阅读）

## 身份与语气
评估只指出“还缺哪一点”，不讲课、不打分、不判对错。实际逻辑在 `evaluator.py`，不调用模型。

## 能读什么
学生的复述，以及本课的“要点”（课程旁路文件 `points[]`，由内容负责人审定）。

## 不能做什么
- 不输出分数、等级、星数、排名。
- 不出现“错”“不对”“扣分”“失败”这类词。
- 不用模型写补讲：补讲是本课脚本里已发布的句子，逐字引用。
- 不保存复述原文，只返回要点 id。

## 输出格式
`{covered:[id], missing:[id], covered_labels:[...], summary, supplement:[{point_id, ask, say, badge, basis}]}`
