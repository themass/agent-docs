# 页面与状态清单

- 配套:`2026-11-01-timeline-interaction-design.md`、`2026-11-01-poem-page-interaction-design.md`、`2026-11-06-chun-wang-sample-spec.md`、`docs/design/DESIGN.md`(视觉与可信三态)。
- 本阶段只跑通《春望》;其他诗显示「场景整理中」,不报错。

## 1. 路由

| 路由 | 视图 | 说明 |
|---|---|---|
| `#/` | 我的时空 | 首页:最近学的诗、推荐一首、进入时间轴的两个入口 |
| `#/timeline` | 时间轴 · 找诗 | 默认模式 |
| `#/timeline/overview` | 时间轴 · 全貌 | 同一条轴,另一种看法 |
| `#/poem/:workId` | 诗词页 | 原文、注释、译文占位、情境对照、出处、「进入那一年」 |
| `#/lesson/:workId/:step` | 五步学习 | `step ∈ read/arrive/meet/return/recite`;任意进入、回看、跳过 |
| `#/parent` | 家长入口(占位) | 本阶段只显示说明与「清除本机学习记录」 |
| `#/settings` | 设置 | 关闭图片与动画、字号、拼音、学段、重置匿名身份 |

路由用 hash:Capacitor 的 `capacitor://localhost` 与 Web 静态托管都不需要服务器回退配置。

## 2. 全局状态(`store`)

| 键 | 内容 | 持久化 | 来源 |
|---|---|---|---|
| `audience` | `PRIMARY` / `JUNIOR` | 本机 | 设置 |
| `prefs` | `mediaOff`、`pinyin`、`fontScale` | 本机 | 设置 |
| `device` | `{deviceId, deviceKey}` | 本机(壳里换安全存储) | `POST /devices` |
| `net` | `online`、`weak` | 否 | `platform.loader.probe` + `navigator.onLine` |
| `env` | `reducedMotion`、`lowMemory` | 否 | `platform.graphics` |
| `source` | `live` / `demo-fixture` / `offline-cache` | 否 | 响应头与缓存命中 |
| `progress[workId]` | `{enteredAt, lastStep, visited[], missingPoints[]}` | 本机,并同步到 Java | 课程控制器 |

派生:`mediaCeiling = ceiling({forceLevel: mediaOff ? 'L0' : undefined, weakNetwork, lowMemory, reducedMotion})`,用内核 `ceiling()`,不另写一套。

## 3. 各页面

### 3.1 我的时空(`#/`)
- 内容:① 继续上次(有 `lastStep` 时显示「回到《春望》·到」);② 推荐一首(来自已发布且有课程入口的作品;本阶段只有《春望》);③ 两个入口:「找一首诗」「看看全貌」。
- 状态:`loading`(骨架)/ `ready` / `empty`(没有已发布课程:显示「这里还在整理」,时间轴入口仍可用)/ `error`(显示重试,保留本地缓存的内容)。
- 不显示:分数、排行、打卡、连续天数。

### 3.2 时间轴 · 找诗
- 轴上元素:朝代色带、事件竖线、诗人生命线、作品点(课本诗为方点);选中变朱砂色,无关淡到 0.25;选中诗人后下方出摘要条与「看他的一生」(本阶段链接到诗人所写作品列表)。
- 缩放:`L0 朝代 / L1 分期 / L2 事件 / L3 诗人与作品` 四档,按钮与键盘 `+` `-` 缩放,触屏捏合延后(见「已知缺口」)。**本阶段用按钮与滑杆,不做手势惯性。**
- **覆盖声明**:轴顶部常驻一句覆盖声明(来自 API 的 `coverageNotice`)。没有已发布内容的区间画成灰色虚线带,文案「这一段还没有整理」,**不留空白,也不画成「历史上没有」**。
- 移动窄屏:切换为纵向列表(朝代 → 时期 → 卡片),规则同上。
- 状态:骨架先出;网络失败显示重试并保留已加载内容。

### 3.3 时间轴 · 全貌
- 三层叠放:朝代层、诗人层(密度)、主题层(线粗细=人数,断点=本轮没有收录)。更安静:没有卡片、没有按钮,只有轴与线。
- 数据只用 API 返回的已发布项;本阶段只有唐代、杜甫、《春望》和一个安史之乱主题,其余朝代画成「未整理」灰虚线带。
- 点任意一年:下方显示「这一年」(已收录的事件/人物/作品;没有就写「这一年我们还没有收录」)。

### 3.4 诗词页(`#/poem/:workId`)
顺序固定,不可调换(先字面,后背景):标题与作者年代 → 原文(拼音开关)→ 「进入那一年」→ 注释 → 情境对照表(时代/处境/触发/对象 ↔ 对应诗句,双向联动)→ 出处与说法(折叠)→ 覆盖声明。
- 争议年代:标题下「757 年或 758 年(两说并存)」,不隐藏、不抢戏。
- 学段回退:所选学段没有对应内容时顶部一条浅提示,正文用可用档。
- 无课程入口(`lesson` 为空):按钮显示「场景整理中」并禁用,其余照常。
- 可信三态:史实靛青下划线(点击出处)、解释青绿左线、演绎朱砂底+「演绎」前缀、未考灰虚线。**任何一条演绎台词不带角标则不渲染该台词**(而不是渲染无角标)。

### 3.5 五步学习

通用外壳:顶部步骤条(读到见回诵,当前高亮,**不显示进度百分比或 2/5**)、「上一步」「下一步」「跳过」「退出」永远可点;说话者条(谁在说:向导/讲解员/诗人 + 「角色扮演」标签);降级提示条(「图没加载出来,文字不受影响」);覆盖声明在页脚。

| 步 | 学生做什么 | 数据 | 可追问动作 | 降级 |
|---|---|---|---|---|
| 读 | 读原文;点字词看注释;选或写「最想弄清哪一句」(可跳过) | 诗文包 | 无(不先讲背景) | 注释缺则不显示 |
| 到 | 四层可点(眼前/这座城/这个天下/这个人),每层 ≤30 秒读完;每层有「回到诗句看一眼」 | bundle `arrive` 四层 + 背景↔诗句 | `open_layer`、`basis` | 图缺→文字卡;地图缺→地名列表 |
| 见 | 看到杜甫(角色),听他说;可问「这有根据吗」 | bundle `meet.roleplay`(演绎,带角标) | `basis`、`decline`(诗人不知道就退场) | 角色清单缺→名牌+文字;agent 缺→固定台词 |
| 回 | 逐句对照:选一句看对应背景,或选背景看对应句 | bundle `return` 与背景关联 | `hint`、`rephrase` | 关联缺→提示「这条背景暂时没绑定诗句」 |
| 诵 | 示范(音频或字幕)→ 自己读 → 用自己的话说「他为什么写这首诗」→ 看补讲 | bundle `recite` + 课程旁路文件的要点 | `recite_prompt`、`rephrase`、`ask_why` | 无音频→拼音与停顿;agent 缺→脚本补讲 |

- **提示「还有一层没看」**:进入下一步时,如果四层有未点开的,最多提示一次「还有一件事你可能想知道」,可忽略;不阻断。
- **只有第一次进入这首诗走完整流程**:再次进入从诗词页直接读;「诵」的复述可单独进入。

### 3.6 复述与补讲(「诵」内)
1. 学生输入一段话(可短,可跳过)。
2. 前端把文本发给 `POST /agent/v1/turn {action:'evaluate_retell'}`。agent 返回 `{covered:[pointId], missing:[pointId], supplement:[{say, basis}]}`。无 agent 时前端用同一份规则做本地评估(规则相同,见 `agent-design.md` §6)。
3. 界面只显示:「你提到了 X、Y」和「还可以想一想:Z」及一两句补讲。**不显示分数、等级、对错、红叉。**
4. 复述原文**留在本机**(用于学生自己回看,可一键删);上传的只有 `missing`/`covered` 的要点 id。

### 3.7 家长入口(占位)
- 家长闸门:做一道算术题 + 文案说明(不是安全验证,只防误触;**真正的家长验证在壳里走原生页**)。
- 本阶段只提供:数据说明(收集什么/不收集什么)、「清除本机学习记录」、「删除云端匿名记录」(调用 `DELETE /devices/me`)。
- 不做:家长报表(后续)、付费、账号。

## 4. 降级矩阵(在这些情况下页面仍可用)

| 失效 | 表现 |
|---|---|
| 图片/动画/角色素材失败 | 对应位置显示降级提示,内容以文字呈现 |
| 用户关闭图片与动画 / 减少动效 / 弱网 / 低内存 | 内核 `ceiling()` 降到 L0/L1;提示条解释原因 |
| agent 不可达/超时/被审校拦下 | 使用 bundle 中的脚本台词,标注「脚本」 |
| Java API 不可达 | 使用本地缓存的诗文包与 bundle(有缓存)或显示重试(无缓存) |
| 角色清单缺失或字段不合法 | 名牌(印章)+ 台词文字 |
| 浏览器无 IndexedDB | 退回内存缓存,功能照常,不持久 |

## 5. 事件(只记结构化行为,不记内容)

`step_enter`、`step_leave`(含停留毫秒)、`step_skip`、`layer_open`、`line_tap`、`ask`(动作名,无文本)、`retell_submit`(只有字数区间,无文本)、`media_degraded`(资产 id 与原因枚举)、`agent_fallback`(原因枚举)。完整字段与白名单见 `api-and-data.md`。
