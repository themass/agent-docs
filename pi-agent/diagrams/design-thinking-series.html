第 3 幕 双层循环

内层 tool+steer · 外层 follow-up

while (true) {                    // 外层：follow-up
  while (tools || steering) {      // 内层：turn
    stream → executeToolCalls → turn_end
    poll steeringQueue
  }
  if (followUpQueue) continue
  break
}
循环触发场景
Innertool_calls 或 steering工具链、运行中改道
OuterfollowUpQueue 非空Agent 本要停，再追加任务
