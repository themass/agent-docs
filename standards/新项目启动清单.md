## Phase 1 — 仓库骨架（W0）

- [ ] `pyproject.toml` / `package.json`，Python `>=3.11,<3.13`
- [ ] `.python-version`（推荐 3.12）
- [ ] `.gitignore`、`.env.example`（无真实密钥）
- [ ] 添加 `agentkit` path 依赖（见 [公共组件包.md](公共组件包.md)）
- [ ] `from agentkit.web import create_app, TraceMiddleware`
- [ ] `src/{pkg}/main.py` + `GET /health`
- [ ] `trace_id` middleware + structlog JSON
- [ ] `apps/web` 空壳（若需要前端）
- [ ] DB migration 工具（Alembic）首版空迁移或核心表
