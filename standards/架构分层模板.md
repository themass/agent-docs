# 架构分层模板（可复用）

| 项 | 内容 |
|---|---|
| 版本 | 1.0 |
| 父文档 | [PROJECT_STANDARD.md](PROJECT_STANDARD.md) |

本文是 **Web + API + Agent** 类产品的默认分层模板。复制到新项目时把 `{pkg}` 换成实际包名（如 `jobcome`）。

---

## 1. 逻辑分层

```text
┌─────────────────────────────────────────────────────────────┐
│ L0  Presentation   apps/web/          UI、路由、客户端状态   │
├─────────────────────────────────────────────────────────────┤
│ L1  API            {pkg}/api/         HTTP、鉴权、DTO 校验    │
├─────────────────────────────────────────────────────────────┤
│ L2  Application    {pkg}/services/    业务编排、事务、规则    │
├─────────────────────────────────────────────────────────────┤
│ L3a Persistence    {pkg}/stores/      DB / Redis 访问         │
│ L3b Integration    {pkg}/adapters/    OSS、邮件、Agent、LLM   │
├─────────────────────────────────────────────────────────────┤
│ Lx  Shared         {pkg}/common/      无业务、可复用工具       │
│                    {pkg}/models/      数据结构 / ORM 模型     │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 目录模板（Python 后端）

```text
src/{pkg}/
├── api/
├── services/          # 业务
├── stores/
├── agent/mcp/tools/   # 产品 MCP（调 services）
└── (无长期 common/ — 用 agentkit)

libs/agentkit/         # ★ 公共包（path 依赖）
├── common/
├── web/
├── adapters/deerflow/
└── mcp/
```

```text
apps/web/
├── app/                    # 路由页（薄）
├── components/
└── lib/                    # ★ 沉淀：api/, auth/, format/
```

---

## 3. 依赖规则（硬）

```text
允许:
  api        → services, models, common, api.deps
  services   → stores, adapters, models, common
  stores     → models, db session
  adapters   → models, common（agentkit）, 必要时 services
  agent/mcp  → services
  产品代码   → agentkit（公共）, 禁止 import deerflow

禁止:
  产品任意层 → import deerflow（用 agentkit.adapters.deerflow）
  产品内     → 与 agentkit 双份维护 common/
```

---

## 4. 鉴权模式（推荐）

```text
Request → middleware(trace_id)
       → AuthMiddleware → Actor (Guest | User)
       → require_capability("export")
       → Service(actor, ...)
```

- Service **只认 `Actor`**，不读 Cookie
- 能力列表由 `GET /auth/context` 下发

---

## 5. Agent 扩展模式

```text
Product API
    → agentkit.adapters.deerflow.DeerFlowSessionClient
    → agent/mcp/tools/               ←  产品 tool 调 services
    → skills/public/*.md             ←  Skill 正文
```

| 职责 | 归属 |
|------|------|
| 对话循环、tool loop | Agent harness |
| Profile、题库、导出 | 自有 DB + services |
| 多租户 | Run metadata 写 `user_id`；MCP 不信模型参数 |

---

## 6. 调用链示例

### REST

```text
POST /api/v1/resources
  → router.create()
  → ResourceService.create(actor, dto)
  → ResourceStore.insert()
```

### Agent SSE

```text
POST /agent/sessions → AgentService.start → agent_session_client.create_thread
GET  /agent/sessions/{id}/events → stream_events → SSE 转前端
```

### MCP tool

```text
harness → mcp.tool.profile_patch
      → ProfileService.apply_patch(user_id from metadata)
```

## 7. 表命名

| 规则 | 示例 |
|------|------|
| 前缀 `{xx}_` | `jc_user`, `jc_profile` |
| 小写蛇形 | `jc_interview_question` |
| 主键 | `id` VARCHAR(32) 业务 id |
| 时间 | `created_at`, `updated_at` UTC |
| 软删 | `deleted_at` NULL |

---

## 8. 新项目裁剪

| 不需要 Agent | 删除 `agent/`、`adapters/agent_session_client` |
| 不需要前端 | 仅 `src/{pkg}/`，文档仍保留 API 约定 |
| 单体脚本 | 可不拆 Store，但 **仍** 用 `common/` 沉淀工具 |
