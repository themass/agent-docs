## 2. 产品目标与背景

### 2.1 一句话

把「只能看」的跟读课，做成 **能开口、立刻知道错在哪、明天还想练** 的 10 分钟手机练习器。

### 2.2 目标

| 层级 | 目标 |
|------|------|
| 用户 | 10–15 分钟完成「开口 → 被纠正 → 愿意明天再来」 |
| 商业 | 3 个月内验证 Play 订阅（免费限额 → Pro） |
| 战略 | 第一个可上架、可收费、可迭代的 C 端 AI 产品 |

### 2.3 痛点与切入点

| 现状 | 问题 |
|------|------|
| B 站/YouTube 跟读 | 不能开口纠错 |
| 通用 AI 聊天 | 无标准句、无进度 |
| ELSA / Speak | 重、贵、或偏自由对话 |
| 独自跟读 | 不知道漏了哪个词 |

**切入点**：精品短课 × 句级跟读 × **对齐优先**的即时反馈 × 每日 10 句打卡。

### 2.4 不做什么（v1）

通用聊天、无限 AI 生成课、短视频躺赚、音素级实验室、社交广场、UGC 平台。

## 3. 定位

**SayAgain** — 面向 **东南亚与中东** 非母语者的英语跟读纠错 App：听一句、跟一句、立刻知道漏了哪个词，**英语 + 本地语** 短反馈，每天 10 分钟打卡。

> 此前「面向中文用户」的定位已废弃。中国区不是 v1 目标；Play 海外 + 新兴市场中高英语需求才是主战场。

| 维度 | 描述 |
|------|------|
| 人群 | 18–35 岁，有基础读写、**开口弱**；动机 = 就业 / 升学 / 出海工作 |
| 设备 | Android + Google Play；耳机、通勤碎片时间 |
| 付费 | **$2–4/月** 档（新兴市场 ARPU）；年付 / 终身作促销锚点 |
| 首发国 | **印尼、越南、沙特、阿联酋**（见 §3.1） |

### 3.1 市场调研摘要（公开数据，2025–2026）

仓库内 **无独家调研**；以下为可引用的第三方与行业信号，供定位校准。

**为什么东南亚 + 中东更对：**

| 信号 | 数据 / 来源 |
|------|-------------|
| 市场规模 | 东南亚在线语言学习约 **$13 亿（2023）**，CAGR **~20%**（Antom）；东南亚英语培训整体 **~$55 亿（2032）**，CAGR **~10%**（Meticulous Research） |
| 人口与设备 | 东南亚 **~7 亿** 人，**60%+ 未满 35 岁**；智能手机为主力学习设备，Play 分发成熟（Antom） |
| 英语刚需 | 制造业出口、BPO、旅游服务业、跨国就业 — 越南 Edupia 三年 **50 万付费**；印尼小学起强制英语（Mordor / 各国教改） |
| 口语短板 | EF EPI 2025：**全球半数国家口语为最弱项**；沙特 **#115/123**、泰国 **#116**、印尼 **#80**、越南 **#64** |
| 中东推力 | 沙特 Vision 2030、海湾年轻人口、经济多元化 → 英语与就业强绑定（6W Research / DataInsights MEA） |
| 竞品验证 | **ELSA** 在印尼、越南重度本地化（定价、官网、客服）；印尼 Play 评论常见 **「好用但 Premium 太贵」** — 留出低价跟读位 |

**分国优先级（建议 v1 聚焦）：**

| 优先级 | 国家 | EF 2025 | 为什么 |
|--------|------|---------|--------|
| P0 | **印尼** | 471（低） | 2.75 亿人口、Play 渗透高、英语与就业强相关、竞品已教育市场 |
| P0 | **越南** | 500（中低） | 跟读/发音付费习惯成熟（ELSA 越南站、本地化年付促销） |
| P1 | **沙特** | 404（极低） | 政府推英语、年轻人口、付费能力高于东南亚均值 |
| P1 | **阿联酋** | — | 外籍劳工 + 本地升学，英语场景多（酒店、零售、客服） |
| P2 | **泰国** | 402（极低） | 旅游与服务英语需求大，但 EF 分更低、需更简 UI |
| 观望 | **菲律宾** | 569（高） | 整体英语好，但 BPO **口音标准化** 仍是细分需求，非 v1 主盘 |

**SayAgain 在这些市场的楔子（相对 ELSA / Speak / Duolingo）：**

- **更轻**：每日 10 句时间盒，不搞大课包和社交
- **更可解释**：句级「漏了哪个词」，不堆吓人的音素分
- **更便宜**：对标 ELSA 年付 **$30+** 与本地促销价，Pro **$2.99–3.99/月** 或区域定价
- **场景更贴地**：咖啡店、酒店前台、工厂报工、客服话术 — 比「留学面试」更贴东南亚/中东打工人

**风险（需产品验证，非纸上谈兵）：**

- ASR 对 **带本地口音的英语** 是否够用（必须在印尼/越南样本上测，不能只在标准美音上自嗨）
- 教练需 **id / vi / ar** 母语解释，不能长期用中文占位
- 沙特等国有 Play / 内容政策差异；部分竞品在个别国家 Play 不可用（ELSA FAQ 有提及）
- 新兴市场 **付费率低于欧美**，要靠量 + 低 CAC（ASO、TikTok/Reels 15s 纠错对比）

### 用户场景

| 优先级 | 场景 | 产品应 |
|--------|------|--------|
| P0 | 每日跟读 | 进度环 + 一句一闭环 |
| P0 | 跟读纠错 | 对齐分 + 英语 + 本地语教练 |
| P0 | 再练 | 高亮漏词/错词 |
| P1 | 看示范 | 循环播放、变速 |
| P1 | 打卡 | 连胜 |
| P2 | 周报 | 完成率趋势（Pro） |

### 核心循环

```text
听示范 → 按住跟读 → ASR → 对齐打分 → en + local 教练 → [再练|下一句] → 今日完成
```

**原则**：Layer 1 对齐（确定性）→ Layer 2 教练（LLM 只读 `issues`，不瞎编）。

## 4. 指标与打法

**北极星**：周活用户的「有效练习句数」（完成跟读且收到反馈的句数 / 周活）。

| 指标 | MVP 目标 |
|------|----------|
| 7 日留存 | > 25% |
| 日均完成句数 | ≥ 8 |
| 「纠错有帮助」 | > 4/5 |
| 免费→Pro | > 3% |
| 月 AI 成本 | < 收入 25% |

**产品打法**：一件事、每日 10 句时间盒、先对齐再教练、MVP 只 1 门完整课。

**获客**：

- ASO（印尼语 / 越南语 / 阿语关键词：`latihan bahasa Inggris`、`luyện nói`、`تحسين النطق` + `shadowing` / `pronunciation`）
- TikTok / Reels / YouTube Shorts：15s「漏词高亮」前后对比
- 当地英语学习 Facebook 群、Telegram（中东）、越南/印尼 KOL 微测评（低成本）

**差异化**：比 Speak 更轻更便宜；比 Duolingo 更偏「说出口」；比 ELSA **更便宜、句级反馈更直观**（不主打音素实验室）。

## 5. 产品设计

### 5.1 信息架构

```text
今日（Home）— 进度环、继续练习、连胜
课程（Courses）— 咖啡店（免费）、面试/旅行（Pro）
我的（Profile）— 订阅、历史、设置
```

MVP 可只有 **今日 + 练习页**。

### 5.2 练习页（核心）

```
标准句 + 示范音（可循环/变速）
      ↓
   按住跟读
      ↓
完整度 + 漏词高亮 + coach.en / coach.local（id·vi·ar）
      ↓
[ 再练一遍 ]  [ 下一句 ]
```

未通过默认高亮「再练」；可强制下一句防挫败。通过计入今日进度。

### 5.3 内容

MVP：**3 主题 × 20–40 句/课**，人工精选，不 AI 批量生成课。

| 课 | 免费/Pro | 贴合市场 |
|----|----------|----------|
| 咖啡店 / 餐厅点餐 | 免费 | 服务业通用 |
| 酒店前台 / 客房 | Pro | 中东旅游、东南亚 hospitality |
| 工厂 / 仓库报工 | Pro | 印尼/越南制造业出口 |
| 客服电话开场 | Pro | BPO、电商、呼叫中心 |

课节 JSON 示例见 `english-shadowing/content/demo_lesson.json`。

### 5.4 订阅

| 档位 | 权益 |
|------|------|
| Free | 15 句/天，1 门课 |
| Pro | 无限句，全课程，周报 · **$2.99–3.99/月**（Play 区域定价）或 **$19.99/年** |

## 7. 评分、及格线与 API

### 7.1 对齐维度

| 维度 | 说明 |
|------|------|
| 完整度 completeness | 标准词是否说齐 |
| 准确度 accuracy | 词是否对（ASR 文本级） |
| 整体 overall | 0.6×完整度 + 0.4×准确度 |

MVP 不做音素级评分（v2 再考虑）。

### 7.2 及格线（`pass_rules.py`）

| 等级 | `grade` | 下一句 | 条件 |
|------|---------|--------|------|
| 优秀 | `excellent` | ✅ | overall≥0.90，completeness≥0.92，无错词 |
| 通过 | `pass` | ✅ | overall≥0.72，completeness≥0.75，无实词漏/错 |
| 再练 | `retry` | ❌ | 其余 |

- **功能词**（a/the/to/please 等）漏读 → 仍可通过，教练会提示  
- **实词**（latte/oat 等）漏或错 → retry  
- 仅多说词（extra）不挡通过  

### 7.3 API：`POST /v1/shadow/evaluate`

**Request**（Phase 1 可传 `audio`；MVP 可先只传 `transcript`）

```json
{
  "sentence_id": "cafe_03",
  "reference": "I'd like a latte, please.",
  "transcript": "I'd like latte please"
}
```

**Response**

```json
{
  "score": { "overall": 0.9, "completeness": 0.833, "accuracy": 1.0 },
  "issues": [{ "type": "missing", "word": "a", "hint": "漏读了「a」" }],
  "coach": {
    "en": "Almost — don't skip «a». Try again.",
    "local": "Hampir — jangan lewatkan «a». Coba lagi.",
    "locale": "id"
  },
  "grade": "pass",
  "pass": true,
  "pass_reason": "acceptable_with_minor_issues"
}
```

## 8. 技术与实现

```text
Android (Compose) — 播放 · 录音 · UI
        │ HTTPS（密钥在服务端）
API — POST /v1/shadow/evaluate
        │
   DashScope ASR (Paraformer)
        │
   alignment.py → pass_rules.py → coach.py
```

### Phase 0（已完成）

| 文件 | 作用 |
|------|------|
| `alignment.py` | 词级对齐 |
| `pass_rules.py` | 三级及格 |
| `coach.py` | 教练（规则 + LLM；开发期 zh 占位，上线改 id/vi/ar） |
| `pipeline.py` | `evaluate()` |
| `self_check.py` | 回归测试 |

```bash
cd agent-research/english-shadowing && python3 self_check.py
```

环境变量见 `english-shadowing/.env.example`（`SAYAGAIN_ASR_*`、`SAYAGAIN_LLM_*`）。

### Phase 1 待做

- [ ] FastAPI 封装 evaluate + DashScope ASR 上传音频
